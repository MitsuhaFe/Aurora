# 桌面伙伴动画系统使用指南

## 📖 概述

桌面伙伴动画系统为VRM模型提供了丰富的动画功能，包括内置的程序化动画（呼吸、眨眼、表情）和自定义动画文件支持。

## ✨ 主要功能

### 1. **内置动画**

#### 🌬️ 呼吸动画
- **功能**: 模拟自然的呼吸起伏效果，通过胸部区域的缩放实现
- **设置项**:
  - 启用/禁用开关
  - 呼吸速度：0.5x - 2.0x（默认 1.0x）
- **实现原理**: 使用正弦波函数控制胸部骨骼的Y轴缩放

#### 👁️ 眨眼动画
- **功能**: 自动眨眼效果，让模型更加生动
- **设置项**:
  - 启用/禁用开关
  - 眨眼间隔：1-10秒（默认 3秒）
- **实现原理**: 使用VRM的表情系统（BlendShape）控制眼睛开合

#### 😊 表情系统
- **功能**: 切换模型的面部表情
- **支持的表情**:
  - 😐 自然 (neutral)
  - 😊 开心 (happy)
  - 😠 生气 (angry)
  - 😢 悲伤 (sad)
  - 😲 惊讶 (surprised)
  - 😌 放松 (relaxed)
- **设置项**:
  - 表情选择
  - 表情强度：0-100%（默认 80%）
- **实现原理**: 使用VRM的ExpressionManager控制标准表情BlendShape

### 2. **自定义动画**

#### 📁 支持的格式

当前版本支持以下动画格式：

- **VRMA** (.vrma) - VRM Animation 官方专用格式 ⭐⭐⭐ 最推荐
  - VRM 1.0 官方动画格式
  - 100% 兼容性保证
  - 支持完整的 VRM 特性（表情、视线等）
  - 文件扩展名：`.vrma`
  
- **GLTF/GLB + VRM Animation** (.gltf/.glb) - 带 VRM 扩展的 GLTF ⭐⭐ 推荐
  - GLTF 文件内包含 VRM Animation 扩展
  - 高兼容性
  - 支持 VRM 特有的表情和骨骼
  
- **标准 GLTF 动画** (.gltf/.glb) - 通用的 GLTF 动画格式 ⭐ 支持
  - 可以使用（回退模式）
  - 需要骨骼名称与 VRM 模型匹配
  - 推荐使用 Mixamo 等平台导出

#### 🚫 需要转换的格式

由于骨骼结构差异，以下格式需要先转换才能使用：
- **VMD** (.vmd) - MikuMikuDance 动画格式
  - MMD 官方格式，海量免费资源
  - 需使用 Blender + Cats 插件转换为 VRMA
  - 详见：《VMD动画使用指南.md》
- **FBX** - Autodesk FBX 动画文件（需转换为 GLTF）
- **BVH** - 动作捕捉数据格式（需转换为 GLTF）

#### 🔄 格式转换方法

**重要**：VMD、FBX、BVH 格式都需要转换后才能使用。

转换工具：

**1. Blender（免费，推荐）**
```
步骤：
1. 下载并安装 Blender (https://www.blender.org/)
2. 安装 VRM 插件和 Cats Blender Plugin
3. 导入 FBX/BVH 文件（File → Import）
4. 调整动画和骨骼（如需要）
5. 导出为 GLTF（File → Export → glTF 2.0）
6. 确保勾选 "VRM Animation" 选项
```

**2. FBX2glTF（命令行工具）**
- GitHub: https://github.com/facebookincubator/FBX2glTF
- 适合批量转换

**3. 在线转换工具**
- Sketchfab
- GLTFViewer

#### 📦 VRM Animation 资源获取

**官方资源**
1. **VRoid Hub** - https://hub.vroid.com/ (部分模型附带动画)
2. **Booth** - https://booth.pm/ (日本同人市场，搜索 "VRM アニメーション")

**自制动画**
1. 使用 **XR Animator** 进行 AI 动作捕捉
2. 使用 **ThreeDPoseTracker** 从视频生成动画
3. 使用 **Blender** 手工制作动画并导出为 VRM Animation

#### 🎬 动画管理功能
- **导入动画**: 通过文件选择器导入动画文件
- **动画列表**: 显示所有已导入的动画
- **播放控制**: 点击播放/暂停按钮控制动画
- **删除动画**: 从列表中移除不需要的动画
- **播放速度**: 0.5x - 2.0x（默认 1.0x）
- **循环播放**: 所有自定义动画默认循环播放

// 动画配置接口
animationConfig: {
  enableBreathing: boolean;        // 启用呼吸

#### 程序化动画（呼吸/眨眼）
在渲染循环中每帧更新：
```typescript

  vrm.value.update(deltaTime);

  // 呼吸动画
  if (breathingEnabled) {
    const breathScale = 1 + Math.sin(time * breathingSpeed * 2) * 0.015;
    chest.scale.y = breathScale;
  }
  
  // 眨眼动画
  if (blinkingEnabled && time - lastBlinkTime > blinkInterval) {
    // 眨眼逻辑...
  }
}
```

#### 表情切换
使用VRM的ExpressionManager：
```typescript
function playExpression(expression: string, intensity: number) {
  // 重置所有表情
  expressions.forEach(expr => {
    expressionManager.setValue(expr, 0);
  });
  
  // 设置新表情
  expressionManager.setValue(expression, intensity);
}
```

#### 自定义动画加载
使用@pixiv/three-vrm-animation：
```typescript
async function loadCustomAnimation(filePath, loop, speed) {
  // 1. 读取文件
  const fileData = await readBinaryFile(filePath);
  const blob = new Blob([fileData.buffer]);
  const url = URL.createObjectURL(blob);
  
  // 2. 加载动画
  const loader = new GLTFLoader();
  loader.register((parser) => new VRMAnimationLoaderPlugin(parser));
  const gltf = await loader.loadAsync(url);
  
  // 3. 创建动画剪辑
  const vrmAnimation = gltf.userData.vrmAnimations[0];
  const clip = createVRMAnimationClip(vrmAnimation, vrm.value);
  
  // 4. 播放
  mixer = new THREE.AnimationMixer(vrm.value.scene);
  currentAction = mixer.clipAction(clip);
  currentAction.loop = loop ? THREE.LoopRepeat : THREE.LoopOnce;
  currentAction.timeScale = speed;
  currentAction.play();
}
```

## 📝 使用说明

### 基础动画设置

1. **启用呼吸动画**
   - 进入设置 → 动画设置
   - 开启"呼吸动画"开关
   - 调整呼吸速度（可选）

2. **启用眨眼动画**
   - 开启"眨眼动画"开关
   - 调整眨眼间隔（可选）

3. **切换表情**
   - 在"表情"下拉框选择想要的表情
   - 调整表情强度（0-100%）

### 自定义动画导入

1. **准备动画文件**
   - ✅ **VRMA** (.vrma) - VRM Animation 官方格式（推荐）
   - ✅ **GLTF/GLB** (.gltf/.glb) - 通用 GLTF 动画格式
   - ❌ **VMD** (.vmd) - 需要转换为 VRMA（详见《VMD动画使用指南.md》）
   - ❌ FBX、BVH 格式需要先转换（参见上方转换方法）
   - 确保动画与VRM模型兼容

2. **导入动画**
   ```
   设置 → 自定义动画 → 选择动画 → 选择 VRMA/GLTF/GLB 文件
   ```

3. **播放动画**
   - 在动画列表中点击"▶"播放按钮
   - 正在播放的动画会高亮显示

4. **调整播放速度**
   - 播放动画后，使用"动画播放速度"滑块调整
   - 范围：0.5x（慢速）到 2.0x（快速）

5. **停止动画**
   - 点击正在播放动画的"⏸"按钮

6. **删除动画**
   - 点击动画项右侧的🗑️按钮
   - 确认删除

## ⚠️ 注意事项

### 兼容性

1. **表情系统**
   - 并非所有VRM模型都包含完整的表情
   - 如果某个表情不生效，说明模型不支持该表情
   - 使用`getAvailableExpressions()`可查看模型支持的表情

2. **骨骼系统**
   - 呼吸动画需要模型有chest（胸部）骨骼
   - 如果模型骨骼结构特殊，动画效果可能不明显

3. **动画文件**
   - VMD文件可能需要针对特定骨骼结构
   - 部分MMD动画可能与VRM模型骨骼不完全匹配
   - 建议使用专门为VRM设计的动画文件

### 性能优化

1. **避免同时播放多个复杂动画**
   - 自定义动画会覆盖程序化动画（呼吸/眨眼）
   - 停止自定义动画后，程序化动画会继续工作

2. **文件大小**
   - 大型动画文件（>10MB）可能导致加载变慢
   - 建议使用优化过的动画文件

3. **循环播放**
   - 所有自定义动画默认循环播放
   - 如需单次播放，可在代码中修改`loop`参数

## 🐛 故障排除

### 表情不生效
**问题**: 切换表情后没有变化
**解决方案**:
1. 检查模型是否包含该表情的BlendShape
2. 尝试提高表情强度（100%）
3. 查看控制台是否有警告信息

### 自定义动画加载失败

**问题 1**: "不支持的动画格式: .fbx/vmd/bvh"
**解决方案**:
1. 当前版本仅支持 GLTF/GLB 格式
2. 使用 Blender 等工具将 FBX/VMD/BVH 转换为 GLTF
3. 确保导出时选择 VRM Animation 格式

**问题 2**: "文件中未找到VRM动画数据"
**解决方案**:
1. 文件虽然是 GLTF 格式，但不包含 VRM Animation
2. 确认文件是专门为 VRM 设计的动画
3. 重新导出时确保勾选 VRM Animation 选项

**问题 3**: "此文件包含普通GLTF动画，但不是VRM Animation格式"
**解决方案**:
1. 文件是普通的 GLTF 动画，不兼容 VRM
2. 需要使用支持 VRM 的工具重新导出
3. 或使用专门的 VRM Animation 文件

### 呼吸动画不明显
**问题**: 开启呼吸动画后效果不明显
**解决方案**:
1. 提高呼吸速度（1.5x-2.0x）
2. 检查模型是否有chest骨骼
3. 部分模型骨骼结构特殊，效果可能微弱

### 动画卡顿
**问题**: 播放动画时出现卡顿
**解决方案**:
1. 降低动画播放速度
2. 关闭其他程序释放系统资源
3. 检查动画文件是否过大
4. 尝试关闭不必要的程序化动画
