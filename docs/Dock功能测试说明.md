## 故障排除

### Dock 未显示

1. 检查设置中"显示 Dock 栏"是否开启
2. 查看控制台是否有错误信息
3. 尝试关闭并重新开启 Dock

### 拖动不工作

1. 检查"固定位置"是否开启
2. 确保鼠标按住 Dock 背景区域，而不是图标

### 设置不生效

1. 检查浏览器控制台是否有错误
2. 清除 localStorage 并重启：`localStorage.clear()`
3. 重新打开应用

### 图标点击无反应

1. 检查 Tauri shell 权限是否配置正确
2. 查看控制台错误信息
3. 确保应用程序路径正确

## 开发者注意事项

1. **响应式原理**：使用 Vue 的 `watch` API 监听 Pinia store 变化，通过 Tauri API 直接修改窗口属性
2. **样式应用**：容器样式通过 computed + inline style 应用，确保即时生效
3. **内存管理**：所有事件监听在 `onUnmounted` 中清理
4. **持久化**：使用 localStorage 存储设置和图标列表
5. **性能优化**：CSS 使用 `will-change` 和 GPU 加速，避免重排重绘
