# 桌面伙伴模型旋转功能

## 功能概述

为桌面伙伴添加了3D旋转控制功能，允许用户通过滑块调整VRM模型在三个轴向的旋转角度，实现全方位的姿态调整。

## 功能特性

- ✅ **X轴旋转（俯仰）**：前后翻转模型（0° - 360°）
- ✅ **Y轴旋转（偏航）**：左右转动模型（0° - 360°）
- ✅ **Z轴旋转（翻滚）**：左右倾斜模型（0° - 360°）
- ✅ **实时预览**：调整滑块时立即在桌面伙伴窗口中看到旋转效果
- ✅ **持久化保存**：旋转设置自动保存到 localStorage
- ✅ **角度显示**：直观显示当前旋转角度（度数）

## 旋转轴说明

### X轴旋转（Pitch - 俯仰）
- **0°** - 正常站立姿态
- **90°** - 向后仰
- **180°** - 倒立
- **270°** - 向前倾

### Y轴旋转（Yaw - 偏航）
- **0°** - 正面朝向
- **90°** - 向右转90度（侧面）
- **180°** - 背面朝向
- **270°** - 向左转90度（侧面）

### Z轴旋转（Roll - 翻滚）
- **0°** - 正常直立
- **90°** - 向右倾斜90度
- **180°** - 上下颠倒
- **270°** - 向左倾斜90度

## 使用方法

### 1. 打开桌面伙伴设置

在 Aurora 设置页面中，选择"桌面伙伴"选项卡。

### 2. 找到"模型旋转"部分

在"模型属性"部分下方，可以看到新增的"模型旋转"部分，包含三个旋转滑块。

### 3. 调整旋转角度

- **X轴旋转（俯仰）** - 控制模型前后翻转
- **Y轴旋转（偏航）** - 控制模型左右转向
- **Z轴旋转（翻滚）** - 控制模型左右倾斜

拖动滑块时，桌面伙伴窗口中的模型会立即旋转到新角度。

### 4. 常用角度推荐

| 效果 | X轴 | Y轴 | Z轴 |
|------|-----|-----|-----|
| 正面站立 | 0° | 0° | 0° |
| 背面站立 | 0° | 180° | 0° |
| 左侧面 | 0° | 270° | 0° |
| 右侧面 | 0° | 90° | 0° |
| 俯视 | 90° | 0° | 0° |
| 仰视 | 270° | 0° | 0° |

## 技术实现

### 1. 数据模型 (`src/stores/petStore.ts`)

添加了三个新的旋转参数：

```typescript
export interface PetSettings {
  // ... 其他字段
  rotationX: number; // X轴旋转角度（度数，0-360）
  rotationY: number; // Y轴旋转角度（度数，0-360）
  rotationZ: number; // Z轴旋转角度（度数，0-360）
}
```

默认值都是 `0`（无旋转，正面朝向）。

### 2. 旋转设置方法 (`src/composables/useVrmLoader.ts`)

新增 `setRotation` 方法，自动将角度转换为弧度：

```typescript
// 设置模型旋转（输入角度，自动转换为弧度）
function setRotation(rotationX: number, rotationY: number, rotationZ: number) {
  if (vrm.value) {
    // 将角度转换为弧度（Three.js 使用弧度）
    const radX = (rotationX * Math.PI) / 180;
    const radY = (rotationY * Math.PI) / 180;
    const radZ = (rotationZ * Math.PI) / 180;
    
    vrm.value.scene.rotation.set(radX, radY, radZ);
    console.log('✓ 已设置模型旋转:', { 
      x: rotationX + '°', 
      y: rotationY + '°', 
      z: rotationZ + '°' 
    });
  }
}
```

**重要**：Three.js 使用弧度制，但用户界面使用更直观的角度制，因此需要转换。

### 3. 应用旋转设置 (`src/views/Pet.vue`)

#### 加载模型时应用初始旋转

```typescript
// 应用旋转
vrmLoader.setRotation(
  petStore.settings.rotationX, 
  petStore.settings.rotationY, 
  petStore.settings.rotationZ
);
```

#### 监听设置变化并实时更新

```typescript
// 更新旋转
if (newSettings.rotationX !== undefined || 
    newSettings.rotationY !== undefined || 
    newSettings.rotationZ !== undefined) {
  vrmLoader.setRotation(
    newSettings.rotationX ?? 0,
    newSettings.rotationY ?? 0,
    newSettings.rotationZ ?? 0
  );
}
```

### 4. UI 控件 (`src/views/Settings/PetSettings.vue`)

添加了三个角度滑块：

```vue
<!-- X轴旋转 -->
<div class="setting-item">
  <div class="setting-label">
    <h3>X轴旋转（俯仰）</h3>
    <p>前后翻转模型 (0° - 360°)</p>
  </div>
  <div class="setting-control">
    <input 
      type="range" 
      min="0" 
      max="360" 
      step="5"
      v-model.number="petStore.settings.rotationX"
      @input="handlePetSettingChange"
      class="slider"
    />
    <span class="value-display">{{ petStore.settings.rotationX }}°</span>
  </div>
</div>
```

**步长说明**：使用 5° 的步长，在精度和操作便利性之间取得平衡。

## 数据流程

```
用户拖动旋转滑块
    ↓
PetSettings.vue 更新 petStore.settings.rotationX/Y/Z
    ↓
petStore.updateSettings() 保存到 localStorage
    ↓
petStore 发送 'pet-settings-changed' 事件到桌面伙伴窗口
    ↓
Pet.vue 接收事件，调用 handleSettingsChanged()
    ↓
调用 vrmLoader.setRotation(rotationX, rotationY, rotationZ)
    ↓
将角度转换为弧度（角度 × π / 180）
    ↓
更新 vrm.scene.rotation
    ↓
Three.js 渲染循环中显示新的旋转姿态
```

## 使用场景

### 场景 1：查看角色细节

通过 Y轴旋转可以从不同角度欣赏VRM模型的细节：
- 正面：0°
- 侧面：90° 或 270°
- 背面：180°

### 场景 2：创造个性化姿态

结合多个轴的旋转，创造独特的展示效果：
- 俯视角度：X轴 90°
- 倾斜头部：Z轴 15-30°
- 回眸效果：Y轴 135° + Z轴 10°

### 场景 3：适应不同摆放位置

根据桌面伙伴在屏幕上的位置，调整朝向：
- 桌面伙伴在左侧：Y轴 90°（朝右）
- 桌面伙伴在右侧：Y轴 270°（朝左）
- 桌面伙伴在顶部：X轴 345°（向下看）

## Three.js 旋转系统

### 欧拉角 (Euler Angles)

Three.js 使用欧拉角来表示3D旋转，按照以下顺序应用：
1. X轴旋转（Pitch）
2. Y轴旋转（Yaw）
3. Z轴旋转（Roll）

### 角度与弧度转换

- **角度 → 弧度**：`弧度 = 角度 × π / 180`
- **弧度 → 角度**：`角度 = 弧度 × 180 / π`

例如：
- 90° = π/2 弧度 ≈ 1.5708
- 180° = π 弧度 ≈ 3.1416
- 360° = 2π 弧度 ≈ 6.2832

### 为什么使用角度而非弧度？

虽然 Three.js 内部使用弧度，但我们在用户界面中使用角度，因为：
1. **更直观**：用户更熟悉角度（0°-360°）
2. **易于理解**：90°、180° 等有明确的几何意义
3. **避免错误**：减少用户输入弧度时的计算错误

## 常见问题

### Q1: 为什么旋转后模型看起来怪怪的？

**A**: 这可能是因为多轴旋转组合产生的万向节死锁（Gimbal Lock）现象。建议：
1. 将所有旋转归零
2. 逐个调整单个轴，观察效果
3. 避免同时在多个轴上使用极端角度

### Q2: 如何重置旋转？

**A**: 将所有旋转滑块拖回 0°：
- X轴：0°
- Y轴：0°
- Z轴：0°

### Q3: 能否使用更精细的角度控制？

**A**: 可以！修改 `PetSettings.vue` 中的 `step` 值：

```vue
<input 
  type="range" 
  min="0" 
  max="360" 
  step="1"  <!-- 从 5 改为 1，实现 1° 精度 -->
  v-model.number="petStore.settings.rotationX"
  @input="handlePetSettingChange"
  class="slider"
/>
```

### Q4: 旋转会影响动画吗？

**A**: 不会。旋转只改变模型的姿态，不影响：
- 呼吸动画
- 眨眼动画
- 待机动画

这些动画仍然会在旋转后的模型上正常播放。

### Q5: 为什么 Y轴旋转 180° 后模型变背面了？

**A**: 这是正确的！Y轴旋转控制模型的朝向：
- 0° = 正面
- 180° = 背面（转身）

如果想看背面的细节，这个功能非常有用。

### 技巧 2：与缩放和位置配合

旋转 + 缩放 + 位置偏移可以创造完美的展示效果：

1. 先调整缩放到合适大小
2. 通过位置偏移调整画面构图
3. 最后用旋转选择最佳角度

### 技巧 3：动态调整

尝试轻微的旋转角度（5-15°）可以让角色看起来更有生气：
- Z轴 +10° - 可爱的歪头效果
- Y轴 +15° - 侧身看向一侧
- X轴 +5° - 轻微抬头
