# 桌面伙伴背景设置功能

## 功能概述

桌面伙伴现在支持个性化背景设置，提供三种背景模式：
- **透明背景**：经典模式，背景完全透明或半透明
- **纯色背景**：自定义纯色背景，可调节颜色和不透明度
- **图片背景**：使用自定义图片作为背景，支持透明度和模糊效果

## 背景类型详解

### 1. 透明背景 (Transparent)

**适用场景**：
- 希望桌面伙伴融入桌面环境
- 配合智能穿透功能使用
- 追求简洁的视觉效果

**可调节参数**：
- **背景透明度** (0-100%)
  - 0% = 完全透明（默认）
  - 100% = 纯黑色背景

**使用建议**：
- 大多数情况下保持 0% 完全透明
- 如需突出模型，可设置 10-30% 的半透明黑色背景

### 2. 纯色背景 (Color)

**适用场景**：
- 希望背景与桌面主题颜色搭配
- 需要一个简单的纯色背景
- 想要为桌面伙伴增加氛围感

**可调节参数**：
- **背景颜色**：使用颜色选择器选择任意颜色
- **背景不透明度** (0-100%)
  - 0% = 完全透明
  - 100% = 完全不透明

**使用建议**：
- 推荐使用柔和的颜色，如浅蓝、浅粉、浅灰等
- 不透明度建议设置在 50-80% 之间，既有背景又不遮挡下层内容
- 可根据桌面壁纸颜色选择互补色或相近色

**示例配置**：
- 浅蓝背景：`#87CEEB` + 60% 不透明度
- 温暖粉色：`#FFB6C1` + 50% 不透明度
- 深色主题：`#2C3E50` + 70% 不透明度

### 3. 图片背景 (Image)

**适用场景**：
- 希望为桌面伙伴创造独特的场景氛围
- 想要使用喜欢的图片作为背景
- 需要更加个性化的视觉效果

**可调节参数**：
- **背景图片**：选择本地图片文件（支持 PNG、JPG、JPEG、GIF、WEBP、BMP）
- **图片不透明度** (0-100%)
  - 默认 50%
  - 建议范围：30-70%
- **图片模糊度** (0-20px)
  - 0px = 清晰显示（默认）
  - 5-10px = 轻微模糊，突出模型
  - 15-20px = 强烈模糊，营造氛围

**使用建议**：
- 选择色彩柔和、不太复杂的图片作为背景
- 适当调整模糊度可以让模型更加突出
- 不透明度设置在 40-60% 可以在保持背景可见的同时不喧宾夺主
- 图片会自动缩放并居中裁剪以适应窗口大小

**推荐背景图片类型**：
- 风景照片（天空、海洋、森林等）
- 纯色渐变图片
- 抽象艺术图案
- 低对比度的纹理图片

## 设置路径

1. 打开 **设置** 页面
2. 点击左侧菜单的 **桌面伙伴**（🐱）
3. 滚动到 **背景设置** 区域
4. 选择背景类型并调整相关参数

## 技术实现

### 文件修改

1. **`src/stores/petStore.ts`**
   - 扩展 `PetSettings` 接口，添加 `background` 配置
   - 添加默认背景设置
   - 在 `loadSettings` 中确保向后兼容

2. **`src/views/Settings/PetSettings.vue`**
   - 添加背景类型选择器
   - 根据背景类型显示不同的设置选项
   - 添加 `selectBackgroundImage` 函数用于选择图片

3. **`src/views/Pet.vue`**
   - 添加 `background-layer` 背景层
   - 使用 `computed` 计算背景样式
   - 根据背景类型应用不同的样式

### 核心代码

#### 背景设置接口
```typescript
background: {
  type: 'transparent' | 'color' | 'image'; // 背景类型
  opacity: number; // 背景透明度（0.0 到 1.0）
  color: string; // 纯色背景颜色
  imagePath: string | null; // 图片背景路径
  imageOpacity: number; // 图片背景透明度（0.0 到 1.0）
  imageBlur: number; // 图片背景模糊度（0 到 20）
}
```

#### 背景样式计算
```typescript
const backgroundStyle = computed(() => {
  const bg = petStore.settings.background;
  
  if (bg.type === 'transparent') {
    return {
      backgroundColor: `rgba(0, 0, 0, ${bg.opacity})`,
    };
  } else if (bg.type === 'color') {
    const rgb = hexToRgb(bg.color);
    return {
      backgroundColor: `rgba(${rgb.r}, ${rgb.g}, ${rgb.b}, ${bg.opacity})`,
    };
  } else if (bg.type === 'image' && bg.imagePath) {
    const imageUrl = convertFileSrc(bg.imagePath);
    return {
      backgroundImage: `url("${imageUrl}")`,
      backgroundSize: 'cover',
      backgroundPosition: 'center',
      opacity: bg.imageOpacity,
      filter: `blur(${bg.imageBlur}px)`,
    };
  }
  
  return { backgroundColor: 'transparent' };
});
```

## 注意事项

1. **图片加载**：
   - 图片文件需要在本地可访问
   - 使用 Tauri 的 `convertFileSrc` 转换文件路径
   - 大图片可能会影响性能

2. **背景层设计**：
   - 背景层使用 `z-index: -1` 确保在模型下方
   - 使用 `pointer-events: none` 确保不影响鼠标事件
   - 独立的背景层避免影响模型的渲染

3. **性能考虑**：
   - 图片模糊使用 CSS `filter: blur()`，性能良好
   - 背景样式变化会自动响应，即时生效
   - 推荐使用压缩过的图片以提升加载速度

4. **与其他功能的兼容性**：
   - 背景设置与智能穿透功能完全兼容
   - 背景层不会影响模型的交互
   - 设置变化会即时同步到桌面伙伴窗口

## 使用示例

### 示例 1：透明背景 + 智能穿透
```
背景类型：透明背景
背景透明度：0%
智能穿透：启用
```
**效果**：桌面伙伴完全融入桌面，背景区域可穿透

### 示例 2：淡蓝色背景
```
背景类型：纯色背景
背景颜色：#87CEEB (浅蓝色)
背景不透明度：60%
```
**效果**：柔和的浅蓝色背景，模型清晰可见

### 示例 3：风景图片背景
```
背景类型：图片背景
背景图片：选择一张天空照片
图片不透明度：50%
图片模糊度：8px
```
**效果**：模糊的天空背景，营造氛围感，模型突出
