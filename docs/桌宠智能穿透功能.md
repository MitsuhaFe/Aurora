# 桌面伙伴智能穿透功能

> **最新更新**：修复了启用智能穿透后初次移动鼠标到背景上时的显示和穿透问题（2025-11-04）

## 功能概述

智能穿透是一种更加智能的窗口交互方式，它能够**根据鼠标位置自动判断**是否穿透窗口：
- **背景区域**（透明部分）：鼠标穿透，可以点击桌面伙伴后面的内容
- **模型区域**（VRM 3D模型）：不穿透，可以与桌面伙伴交互（拖动、右键菜单等）

这是对传统"完全穿透"模式的重大改进，让桌面伙伴既不妨碍日常操作，又能保持交互性。

## 穿透模式对比

### 🎯 智能穿透（推荐）

**特点**：
- ✅ 背景透明区域可穿透
- ✅ 模型区域可交互
- ✅ 自动检测鼠标位置
- ✅ 动态切换穿透状态

**适用场景**：
- 日常使用（推荐）
- 需要桌面伙伴陪伴但不想影响工作
- 需要偶尔与桌面伙伴交互

### 🌐 完全穿透

**特点**：
- ✅ 整个窗口完全穿透
- ❌ 无法交互
- ⚠️ 只能通过设置页面关闭

**适用场景**：
- 纯观赏模式
- 不需要任何交互

### 🔒 不穿透（默认）

**特点**：
- ✅ 完全可交互
- ❌ 背景也会阻挡鼠标
- ❌ 影响后面的窗口操作

**适用场景**：
- 经常需要与桌面伙伴交互
- 桌面伙伴在屏幕边缘或角落

## 技术实现

### 1. 核心原理

使用 **Three.js Raycaster** 进行实时射线检测 + **定时轮询机制**：

#### 关键问题与解决方案

**问题**：一旦设置 `setIgnoreCursorEvents(true)`（窗口穿透），窗口就无法接收 `mousemove` 事件了！

**解决**：使用双重机制
1. **mousemove 事件**：记录最后的鼠标位置
2. **定时轮询**：使用 `setInterval` 每 16ms（约 60fps）检测一次

```typescript
// 智能穿透相关
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();
let isMouseOverModel = false;
let lastMouseX = 0;
let lastMouseY = 0;
let smartClickThroughInterval: number | null = null;

// 1. 记录鼠标位置（即使窗口穿透，这个事件仍能触发）
document.addEventListener('mousemove', (event: MouseEvent) => {
  lastMouseX = event.clientX;
  lastMouseY = event.clientY;
});

// 2. 定时检测函数
function checkSmartClickThrough() {
  if (!smartClickThrough.value || clickThrough.value || !vrmLoader || !containerRef.value) {
    return;
  }

  // 获取相机和VRM模型
  const camera = vrmLoader.getCamera();
  const vrm = vrmLoader.getVrm();
  
  if (!camera || !vrm) return;

  // 计算鼠标在标准化设备坐标中的位置 (-1 到 +1)
  const rect = containerRef.value.getBoundingClientRect();
  mouse.x = ((lastMouseX - rect.left) / rect.width) * 2 - 1;
  mouse.y = -((lastMouseY - rect.top) / rect.height) * 2 + 1;

  // 使用 raycaster 检测鼠标是否在模型上
  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObject(vrm.scene, true);

  const wasOverModel = isMouseOverModel;
  isMouseOverModel = intersects.length > 0;

  // 只有当状态改变时才更新窗口穿透设置
  if (wasOverModel !== isMouseOverModel) {
    // 鼠标在模型上 → 禁用穿透（可交互）
    // 鼠标在背景上 → 启用穿透
    appWindow.setIgnoreCursorEvents(!isMouseOverModel);
    console.log(isMouseOverModel ? '🖱️ 鼠标在模型上，可交互' : '👻 鼠标在背景上，穿透');
  }
}

// 3. 启动定时检测（每 16ms 检测一次，约 60fps）
smartClickThroughInterval = window.setInterval(checkSmartClickThrough, 16);
```

**为什么这样有效？**
- ✅ `mousemove` 在全局 document 上，即使窗口穿透也能收到事件
- ✅ 定时器持续运行，不依赖窗口事件
- ✅ 即使窗口穿透，仍能检测到鼠标移回模型，并取消穿透

### 2. 工作流程

```
┌─────────────────────────────────────┐
│  全局 mousemove 事件                 │
│  记录 lastMouseX, lastMouseY        │
└─────────────────────────────────────┘
            ↓ 持续记录
┌─────────────────────────────────────┐
│  定时器（每 16ms）                   │
│  checkSmartClickThrough()           │
└─────────────────────────────────────┘
            ↓
    获取最后的鼠标位置
            ↓
    计算归一化设备坐标 (NDC)
            ↓
    使用 Raycaster 发射射线
            ↓
    检测射线是否与 VRM 模型相交
            ↓
    ┌─────────────┬─────────────┐
    │  有交点      │  无交点      │
    │ (在模型上)   │ (在背景上)   │
    └─────────────┴─────────────┘
         ↓               ↓
    禁用穿透       启用穿透
    可以交互       穿透到后面
         ↓               ↓
    ┌─────────────────────────────┐
    │  下一次循环（16ms 后）        │
    └─────────────────────────────┘
```

**关键点**：
- 🔄 定时器持续运行，即使窗口穿透
- 📍 全局 mousemove 始终能记录位置
- ⚡ 16ms 间隔 = 约 60fps，流畅响应

### 3. 关键技术点

#### 归一化设备坐标（NDC）

鼠标坐标需要从屏幕空间转换到 NDC 空间（-1 到 +1）：

```typescript
const rect = containerRef.value.getBoundingClientRect();
mouse.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
mouse.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
```

注意：Y轴需要反转（屏幕坐标 Y 向下，NDC Y 向上）

#### Raycaster 射线检测

```typescript
raycaster.setFromCamera(mouse, camera);
const intersects = raycaster.intersectObject(vrm.scene, true);
```

- `setFromCamera`: 从相机位置向鼠标方向发射射线
- `intersectObject`: 检测射线与对象的交点
- 第二个参数 `true`：递归检测所有子对象

#### 状态缓存优化

```typescript
const wasOverModel = isMouseOverModel;
isMouseOverModel = intersects.length > 0;

// 只有当状态改变时才更新
if (wasOverModel !== isMouseOverModel) {
  appWindow.setIgnoreCursorEvents(!isMouseOverModel);
}
```

避免每次鼠标移动都调用 Tauri API，只在状态变化时更新。

### 4. 互斥逻辑

智能穿透和完全穿透是互斥的：

**PetSettings.vue**:
```typescript
// 如果启用了智能穿透，禁用完全穿透
if (petStore.settings.smartClickThrough && petStore.settings.clickThrough) {
  petStore.settings.clickThrough = false;
}

// 如果启用了完全穿透，禁用智能穿透
if (petStore.settings.clickThrough && petStore.settings.smartClickThrough) {
  petStore.settings.smartClickThrough = false;
}
```

**Pet.vue**:
```typescript
// 如果启用完全穿透，禁用智能穿透
if (newSettings.clickThrough) {
  smartClickThrough.value = false;
  petStore.settings.smartClickThrough = false;
  appWindow.setIgnoreCursorEvents(true);
} else if (!smartClickThrough.value) {
  // 如果两者都禁用，则不穿透
  appWindow.setIgnoreCursorEvents(false);
}
```

## 性能优化

### 1. 状态缓存

只在鼠标从"背景"移到"模型"或反向时才调用 API：

```typescript
const wasOverModel = isMouseOverModel;
isMouseOverModel = intersects.length > 0;

if (wasOverModel !== isMouseOverModel) {
  // 状态改变时才更新
  appWindow.setIgnoreCursorEvents(!isMouseOverModel);
}
```

### 2. 早期返回

在不需要检测时立即返回：

```typescript
if (!smartClickThrough.value || !vrmLoader || !containerRef.value) {
  return;
}

if (!camera || !scene || !vrm) {
  return;
}
```

### 3. 单次检测

每次鼠标移动只进行一次射线检测，不重复计算。

## 用户体验

### ✅ 优势

1. **智能判断**：自动识别鼠标位置，无需手动切换
2. **不妨碍工作**：背景穿透，不影响点击后面的窗口
3. **保持交互**：模型区域可交互，可以拖动、右键菜单
4. **流畅体验**：状态缓存确保性能，无卡顿

1. **初始状态**：启用智能穿透后，初始状态为背景穿透
2. **模型加载**：模型加载完成后才能正确检测
3. **性能影响**：鼠标移动时会进行射线检测，但经过优化影响很小

## 问题修复历史

### 2025-11-04：修复初次启用智能穿透的显示和穿透问题

**问题描述**：
当刚开启智能穿透时，初次将鼠标移动到桌面伙伴的背景上时会出现以下问题：
1. 显示"四向箭头"光标
2. 实际上并不能拖动
3. 没有实现穿透效果，鼠标不会触发其他窗口和桌面的事件

**问题原因**：
1. **CSS 问题**：`.render-container` 设置了 `cursor: move;`，导致无论鼠标在哪里都显示四向箭头
2. **逻辑问题**：`isMouseOverModel` 初始值为 `false`，当第一次移动到背景上时检测结果也是 `false`，因为状态没有改变，所以不会触发 `setIgnoreCursorEvents(true)`

**修复方案**：
1. **CSS 修复**：
   - 将 `.render-container` 的 `cursor` 从 `move` 改为 `default`
   - 避免在背景区域显示四向箭头

2. **逻辑修复**：
   - 将 `isMouseOverModel` 初始值从 `false` 改为 `true`
   - 启动智能穿透时立即执行一次检测（`await checkSmartClickThrough()`）
   - 确保第一次移动到背景上时能正确触发穿透状态

**修复效果**：
- ✅ 背景区域不再显示四向箭头
- ✅ 启用智能穿透后立即生效，无需等待鼠标移动
- ✅ 第一次移动到背景上时正确触发穿透效果
- ✅ 在模型上仍然可以正常拖动
