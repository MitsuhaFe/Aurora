# Dock 栏快速使用指南

## 🚀 快速开始

### 1. 启动应用

```bash
# 开发模式
npm run tauri:dev

# 或使用生产构建
npm run tauri:build
```

### 2. 查看 Dock

应用启动后，Dock 栏会自动在屏幕底部居中显示，包含 3 个默认图标：
- 💻 此电脑
- ⚙️ 设置
- 🎛️ 控制面板

## 📖 基本操作

### 使用图标

| 操作 | 说明 |
|------|------|
| **左键点击** | 启动对应的应用程序 |
| **右键点击** | 显示菜单，可移除自定义图标 |
| **鼠标悬浮** | 显示图标名称和动画效果 |

### 移动 Dock

1. 用鼠标按住 Dock 的背景区域
2. 拖动到想要的位置
3. 松开鼠标，位置会自动保存
4. 下次启动应用时，Dock 会在这个位置显示

### 添加自定义图标

1. 点击 Dock 上的 ➕ 按钮
2. 选择一个 `.exe` 应用程序文件
3. 新图标会出现在 Dock 上
4. 点击图标即可启动该应用

### 移除图标

**方法一：右键菜单**
1. 右键点击要移除的图标
2. 在弹出的确认对话框中点击"确定"

**方法二：设置页面**
1. 打开设置 → Dock 栏
2. 在"图标管理"区域找到要移除的图标
3. 点击"移除"按钮

> ⚠️ **注意：** 默认图标也可以移除！

## ⚙️ Dock 设置

打开"设置"窗口，进入"Dock 栏"选项卡。

### 基本开关

#### 显示 Dock 栏
- **开启**：显示 Dock 栏
- **关闭**：隐藏 Dock 栏
- 可随时切换

#### 始终置顶
- **开启**：Dock 始终在所有窗口的最顶层
- **关闭**：Dock 按正常窗口层级显示
- 适合需要快速访问应用的场景

#### 固定位置
- **开启**：禁用拖动，Dock 位置被锁定
- **关闭**：可以自由拖动 Dock
- 防止意外移动

#### 自动隐藏
- **开启**：鼠标离开 2 秒后自动隐藏
- **关闭**：Dock 始终显示
- 鼠标移入会立即显示
- 节省桌面空间

### 外观定制

#### 容器属性

| 属性 | 范围 | 说明 |
|------|------|------|
| **长度** | 200-800px | Dock 的宽度 |
| **高度** | 60-120px | Dock 的高度 |
| **透明度** | 50-100% | Dock 的不透明度 |
| **圆角值** | 0-30px | Dock 边框的圆角大小 |
| **背景色** | 任意颜色 | Dock 的背景颜色 |

#### 图标属性

| 属性 | 选项 | 说明 |
|------|------|------|
| **图标大小** | 32-72px | 图标的显示大小 |
| **悬浮动画** | 无/缩放/发光/两者 | 鼠标悬浮时的动画效果 |

> ✨ **提示：** 所有设置立即生效，无需重启应用！

## 💡 使用技巧

### 1. 高效工作流

将常用应用添加到 Dock：
- 浏览器
- 代码编辑器
- 文件管理器
- 截图工具
- 笔记软件

### 2. 自动隐藏场景

适合开启自动隐藏的情况：
- 需要大面积屏幕空间（如游戏、视频编辑）
- 使用小屏幕或笔记本
- 不需要频繁切换应用

不适合自动隐藏的情况：
- 需要频繁点击 Dock 图标
- 多任务处理
- 习惯看到 Dock 在桌面上

### 3. 始终置顶 + 自动隐藏

组合使用这两个功能：
1. 开启"始终置顶"
2. 开启"自动隐藏"
3. 效果：需要时随时呼出，在所有窗口之上

### 4. 固定位置

建议在以下情况启用：
- 找到了完美的位置
- 容易误触拖动
- 多显示器设置

## ❓ 常见问题

### Q: Dock 不显示？
**A:** 检查设置中"显示 Dock 栏"是否开启。

### Q: 拖动不工作？
**A:** 检查"固定位置"是否开启。关闭后即可拖动。

### Q: 图标点击无反应？
**A:** 确保应用程序路径正确。系统应用（此电脑、设置、控制面板）应该都能正常工作。

### Q: 修改设置不生效？
**A:** 
1. 检查浏览器控制台是否有错误
2. 尝试重启应用
3. 清除缓存：打开控制台执行 `localStorage.clear()`

### Q: 如何重置 Dock？
**A:** 
```javascript
// 在浏览器控制台执行
localStorage.removeItem('aurora-dock-settings');
localStorage.removeItem('aurora-dock-icons');
// 然后重启应用
```

### Q: 如何找回移除的默认图标？
**A:** 
1. 打开控制台执行：
```javascript
localStorage.removeItem('aurora-dock-icons');
```
2. 重启应用，默认图标会恢复

### Q: Dock 可以放在顶部或侧边吗？
**A:** 可以！虽然默认在底部，但你可以拖动到任意位置。

### Q: 支持多显示器吗？
**A:** 支持。Dock 会记住在哪个显示器的哪个位置。

## 🎯 最佳实践

1. **位置选择**
   - 底部居中：最符合使用习惯
   - 侧边：适合宽屏显示器
   - 顶部：适合喜欢 macOS 风格的用户

2. **图标数量**
   - 建议：5-8 个图标
   - 太多会显得拥挤
   - 太少无法发挥 Dock 的作用

3. **外观搭配**
   - 深色背景 + 高透明度：现代感
   - 浅色背景 + 低透明度：清新感
   - 大圆角：更柔和
   - 小圆角：更专业

4. **动画选择**
   - 缩放：简洁实用
   - 发光：科技感强
   - 两者：华丽但可能影响性能
