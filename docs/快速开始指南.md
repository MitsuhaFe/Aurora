   node --version  # 应该显示 v18.x.x 或更高

2. **Rust 工具链**
   ```bash
   # 安装 rustup
   https://rustup.rs/
   
   # 验证
   rustc --version
   cargo --version
   ```

3. **包管理器**
   ```bash
   # 推荐使用 pnpm
   npm install -g pnpm
   
   # 或使用 npm
   ```

## 🚀 启动开发环境

### 1. 安装依赖

```bash
# 使用 pnpm（推荐）
pnpm install

# 或使用 npm
npm install
```

### 2. 启动开发服务器

```bash
# 使用 pnpm
pnpm tauri:dev

# 或使用 npm
npm run tauri:dev
```

**首次启动会比较慢**，因为需要：
- 编译 Rust 代码
- 下载 Tauri 依赖
- 启动 Vite 开发服务器

### 3. 仅启动 Vue 开发服务器（不启动 Tauri）

```bash
# 用于快速开发前端 UI
pnpm dev
# 或
npm run dev

# 浏览器访问 http://localhost:5173
```

## 📝 项目约定

### 文件命名
- **Vue 组件：** PascalCase（如 `DockIcon.vue`）
- **Composables：** camelCase with `use` prefix（如 `useTauriBridge.ts`）
- **样式文件：** kebab-case（如 `main.css`）
- **目录：** kebab-case（如 `components/`）

### 代码风格
- 使用 **TypeScript** 严格模式
- 使用 **Vue 3 Composition API**
- 使用 **Pinia** 进行状态管理
- 遵循 **ESLint** 和 **Prettier** 规范

### Git 提交
遵循 **Conventional Commits** 规范：
```
feat(ui): add settings page
fix(router): correct navigation issue
docs(readme): update quick start guide
```
