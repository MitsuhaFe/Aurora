# Aurora 快速开始指南

欢迎使用 Aurora！本指南将帮助你快速启动项目。

---

## 📋 前置要求

在开始之前，请确保已安装以下工具：

### 必需工具
- **Node.js** 18.0+ ([下载](https://nodejs.org/))
- **pnpm** 8.0+ (`npm install -g pnpm`)
- **Rust** 1.70+ ([下载](https://rustup.rs/))

### Windows 用户额外要求
- **Microsoft C++ Build Tools** ([下载](https://visualstudio.microsoft.com/visual-cpp-build-tools/))
- **WebView2** (Windows 11 自带，Windows 10 可能需要安装)

---

## 🚀 快速启动

### 方法一：使用初始化脚本（推荐）

**Windows：**
```bash
# 运行初始化脚本
.\scripts\init-project.bat
```

脚本会自动完成：
- ✅ 检查环境
- ✅ 安装 pnpm
- ✅ 创建目录结构
- ✅ 安装依赖
- ✅ 初始化 Git

### 方法二：手动安装

```bash
# 1. 安装依赖
pnpm install

# 2. 启动开发服务器
pnpm tauri dev
```

## 🎮 可用命令

### 开发命令

```bash
# 启动开发服务器（前端）
pnpm dev

# 启动 Tauri 开发模式（前端 + 应用）
pnpm tauri dev

# 代码检查
pnpm lint

# 代码格式化
pnpm format
```

### 构建命令

```bash
# 构建前端
pnpm build

# 构建 Tauri 应用（生产版本）
pnpm tauri build

# 构建输出位置
# Windows: src-tauri/target/release/bundle/msi/
```

## 🖥️ 首次启动

1. **运行开发服务器**
   ```bash
   pnpm tauri dev
   ```

2. **等待编译完成**
   - 首次运行需要下载和编译 Rust 依赖
   - 约需 5-10 分钟（取决于网络和电脑性能）

3. **应用启动后**
   - 主窗口会自动打开，显示设置面板
   - 系统托盘会显示 Aurora 图标
   - 右键托盘图标可以显示/隐藏 Dock

## 🐛 常见问题

### 问题 1: "pnpm: 无法加载文件"（Windows PowerShell）

**原因：** PowerShell 执行策略限制

**解决方案：**
```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 问题 2: Rust 编译失败

**可能原因：**
- Rust 版本过低
- 缺少 Microsoft C++ Build Tools（Windows）

**解决方案：**
```bash
# 更新 Rust
rustup update

# Windows: 安装 Visual Studio Build Tools
# https://visualstudio.microsoft.com/visual-cpp-build-tools/
```

### 问题 3: 端口 5173 被占用

**错误信息：** `Port 5173 is in use`

**解决方案：**
```bash
# 方法 1: 关闭占用端口的程序
# Windows
netstat -ano | findstr :5173
taskkill /PID <进程ID> /F

# 方法 2: 修改 vite.config.ts 中的端口
# server: { port: 5174 }
```

### 问题 4: WebView2 未安装（Windows 10）

**错误信息：** `WebView2 is not installed`

**解决方案：**
下载并安装 WebView2 Runtime
https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section

## 💡 提示

### 开发技巧
1. **热重载：** 修改 Vue 代码会自动刷新
2. **调试：** 按 F12 打开 DevTools
3. **Rust 日志：** Rust 的 println! 会输出到终端

### 性能建议
1. 开发模式下内存占用较高（约 200-300MB）
2. 生产构建会大幅减小体积和内存占用
3. 首次 Rust 编译较慢，后续会快很多
