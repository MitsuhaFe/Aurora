# VRM 加载问题诊断指南

## 常见错误及解决方案

### 1. "文件不包含有效的VRM数据"

**原因：**
- 文件不是VRM格式
- 文件已损坏
- 文件不是VRM 0.0或1.0规范

**解决方案：**
```bash
✅ 确认文件扩展名为 .vrm
✅ 从可信源下载模型（如 VRoid Hub）
✅ 使用VRoid Studio导出时选择正确的版本
✅ 尝试用其他VRM查看器验证文件
```

### 2. "文件不存在或无法访问"

**原因：**
- 文件路径包含特殊字符
- 文件被占用或锁定
- 权限不足

**解决方案：**
```bash
✅ 将VRM文件移动到简单路径（如 C:\Models\model.vrm）
✅ 确保文件名不包含中文或特殊字符
✅ 关闭其他可能占用文件的程序
✅ 以管理员身份运行Aurora
```

### 3. "3D场景未正确初始化"

**原因：**
- WebGL不支持
- 显卡驱动问题
- 浏览器内核问题

**解决方案：**
```bash
✅ 更新显卡驱动
✅ 检查浏览器WebGL支持：访问 webglreport.com
✅ 重启应用
✅ 清除应用缓存
```

### 4. "网络错误，请检查文件路径"

**原因：**
- 文件路径转换失败
- Tauri安全策略限制

**解决方案：**
```bash
✅ 选择本地文件而非网络路径
✅ 确保文件在可访问的磁盘上
✅ 避免使用网络映射驱动器
```

### 步骤 3：定位错误位置

查看错误出现在哪一步：

- **在"开始加载"前出错** → 文件路径或选择问题
- **在"下载模型"时出错** → 文件访问权限问题
- **在"解析VRM数据"时出错** → VRM文件格式问题
- **在"添加到场景"后出错** → 模型内容问题

## 推荐的测试模型

### 免费测试模型

1. **VRoid Hub 官方示例**
   - 访问：https://hub.vroid.com/
   - 搜索："Free" 或 "CC0"


### 推荐测试流程

```bash
1️⃣ 使用小型简单模型测试（< 10MB）
2️⃣ 确认基本功能正常
3️⃣ 尝试加载目标模型
4️⃣ 如果失败，对比两个模型的差异
```

## VRM 文件要求

### 支持的版本
- ✅ VRM 0.0
- ✅ VRM 1.0
- ❌ VRM 1.0-draft（不推荐）

### 文件大小建议
- 推荐：< 50MB
- 最大：< 200MB
- 超大文件可能导致加载缓慢或内存不足

### 必需组件
- ✅ 网格（Meshes）
- ✅ 材质（Materials）
- ✅ 纹理（Textures）
- ⚠️ Humanoid骨骼（推荐但非必需）
- ⚠️ BlendShapes（推荐但非必需）

## 常见问题解答

### Q: 为什么模型加载很慢？
A: 可能原因：
- 模型文件太大
- 纹理分辨率过高
- 显卡性能不足

**解决方案：**
```bash
✅ 使用较小的模型文件
✅ 降低纹理分辨率
✅ 关闭其他占用GPU的程序
```

### Q: 模型显示是黑色的？
A: 可能原因：
- 光照设置不当
- 材质问题
- 法线反向

**解决方案：**
```bash
✅ 在设置中调整光照亮度
✅ 调整环境光颜色
✅ 尝试不同的VRM模型
```

### Q: 模型太大或太小？
A: 使用缩放功能：
```bash
✅ 打开设置 → 桌面伙伴 → 模型缩放
✅ 调整范围：0.5x - 2.0x
✅ 实时预览效果
```

### Q: 动画不工作？
A: 检查：
```bash
✅ 确认动画开关已开启
✅ 检查模型是否包含 Humanoid 骨骼
✅ 检查模型是否包含 BlendShapes
✅ 查看控制台是否有警告信息
```

## 性能优化建议

### 选择合适的模型
```bash
✅ 多边形数量：< 50,000 推荐
✅ 纹理大小：2048x2048 或更小
✅ 材质数量：< 10 个
✅ 骨骼数量：< 100 个
```

### 优化设置
```bash
✅ 降低光照亮度可减少GPU负载
✅ 关闭不需要的动画效果
✅ 使用较小的模型缩放
```


## 最佳实践

### ✅ 推荐做法
1. 使用官方源下载的VRM模型
2. 将模型文件放在简单路径
3. 先用小模型测试功能
4. 定期更新显卡驱动
5. 保持Aurora更新到最新版本

### ❌ 避免做法
1. 使用来源不明的VRM文件
2. 文件路径包含特殊字符
3. 同时加载多个大型模型
4. 在低配置电脑上使用超大模型
5. 修改VRM文件内部结构

---

**提示：** 90% 的加载问题都是由于文件格式或路径问题导致的。请首先确认VRM文件本身是有效的！
