# 桌面伙伴模型位置偏移功能

## 功能概述

为桌面伙伴添加了模型位置微调功能，允许用户通过滑块精确调整VRM模型在窗口内的水平和垂直位置。

## 功能特性

- ✅ **水平位置偏移**：左右移动模型（-2.0 到 2.0）
- ✅ **垂直位置偏移**：上下移动模型（-2.0 到 2.0）
- ✅ **实时预览**：调整滑块时立即在桌面伙伴窗口中看到效果
- ✅ **持久化保存**：位置设置自动保存到 localStorage
- ✅ **精确控制**：0.1 的调整步长，可精确定位

## 使用方法

### 1. 打开桌面伙伴设置

在 Aurora 设置页面中，选择"桌面伙伴"选项卡。

### 2. 调整位置偏移

在"模型属性"部分，你会看到三个滑块：

1. **模型缩放** - 调整模型大小（0.5x - 2.0x）
2. **水平位置偏移** - 左右移动模型（-2.0 到 2.0）
   - 负值：向左移动
   - 正值：向右移动
3. **垂直位置偏移** - 上下移动模型（-2.0 到 2.0）
   - 负值：向下移动
   - 正值：向上移动

### 3. 实时预览

拖动滑块时，桌面伙伴窗口中的模型会立即移动到新位置。

## 技术实现

### 1. 数据模型 (`src/stores/petStore.ts`)

添加了两个新的设置字段：

```typescript
export interface PetSettings {
  // ... 其他字段
  modelOffsetX: number; // 模型左右偏移（-2.0 到 2.0）
  modelOffsetY: number; // 模型上下偏移（-2.0 到 2.0）
}
```

默认值都是 `0.0`（无偏移）。

### 2. 位置设置方法 (`src/composables/useVrmLoader.ts`)

新增 `setPosition` 方法来设置模型的3D空间位置：

```typescript
// 设置模型位置偏移
function setPosition(offsetX: number, offsetY: number) {
  if (vrm.value) {
    vrm.value.scene.position.set(offsetX, offsetY, 0);
    console.log('✓ 已设置模型位置偏移:', { x: offsetX, y: offsetY });
  }
}
```

**坐标系说明**：
- **X轴**：水平方向（正值向右，负值向左）
- **Y轴**：垂直方向（正值向上，负值向下）
- **Z轴**：深度方向（固定为0，保持在相机正前方）

### 3. 应用位置偏移 (`src/views/Pet.vue`)

#### 加载模型时应用初始位置

```typescript
// 加载模型后
vrmLoader.setPosition(petStore.settings.modelOffsetX, petStore.settings.modelOffsetY);
```

#### 监听设置变化并实时更新

```typescript
function handleSettingsChanged(newSettings: any) {
  // ... 其他设置
  
  // 更新位置偏移
  if (newSettings.modelOffsetX !== undefined || newSettings.modelOffsetY !== undefined) {
    vrmLoader.setPosition(
      newSettings.modelOffsetX ?? 0,
      newSettings.modelOffsetY ?? 0
    );
  }
}
```

### 4. UI控件 (`src/views/Settings/PetSettings.vue`)

添加了两个范围滑块控件：

```vue
<!-- 水平位置偏移 -->
<div class="setting-item">
  <div class="setting-label">
    <h3>水平位置偏移</h3>
    <p>调整模型左右位置 (-2.0 到 2.0)</p>
  </div>
  <div class="setting-control">
    <input 
      type="range" 
      min="-2.0" 
      max="2.0" 
      step="0.1"
      v-model.number="petStore.settings.modelOffsetX"
      @input="handlePetSettingChange"
      class="slider"
    />
    <span class="value-display">{{ petStore.settings.modelOffsetX.toFixed(1) }}</span>
  </div>
</div>

<!-- 垂直位置偏移 -->
<div class="setting-item">
  <div class="setting-label">
    <h3>垂直位置偏移</h3>
    <p>调整模型上下位置 (-2.0 到 2.0)</p>
  </div>
  <div class="setting-control">
    <input 
      type="range" 
      min="-2.0" 
      max="2.0" 
      step="0.1"
      v-model.number="petStore.settings.modelOffsetY"
      @input="handlePetSettingChange"
      class="slider"
    />
    <span class="value-display">{{ petStore.settings.modelOffsetY.toFixed(1) }}</span>
  </div>
</div>
```

## 数据流程

```
用户拖动滑块
    ↓
PetSettings.vue 更新 petStore.settings
    ↓
petStore.updateSettings() 保存到 localStorage
    ↓
petStore 发送 'pet-settings-changed' 事件到桌面伙伴窗口
    ↓
Pet.vue 接收事件，调用 handleSettingsChanged()
    ↓
调用 vrmLoader.setPosition(offsetX, offsetY)
    ↓
更新 vrm.scene.position
    ↓
Three.js 渲染循环中显示新位置
```

## 使用场景

### 场景 1：模型被窗口边缘裁剪

如果VRM模型的某些部分被窗口边缘裁剪了：
- 使用**垂直位置偏移**向下移动模型
- 或者使用**水平位置偏移**调整左右位置

### 场景 2：模型居中不理想

某些VRM模型的原点可能不在中心：
- 通过位置偏移微调，使模型在窗口中更好地居中显示

### 场景 3：配合缩放使用

先调整缩放到合适大小，再通过位置偏移微调最终显示效果。

## 参数范围说明

### 为什么是 -2.0 到 2.0？

这个范围基于Three.js的场景单位和相机设置：

```typescript
// 相机配置
camera.value = new THREE.PerspectiveCamera(
  30,  // 视野角度
  container.clientWidth / container.clientHeight,
  0.1,
  20
);
camera.value.position.set(0, 1.3, 2.5);
camera.value.lookAt(0, 1.2, 0);
```

- 相机位于 (0, 1.3, 2.5)
- 看向 (0, 1.2, 0)
- ±2.0 的偏移足够覆盖大部分调整需求
- 更大的偏移可能导致模型超出视野范围

如果需要更大范围，可以在 `PetSettings.vue` 中修改 `min` 和 `max` 值。

## 常见问题

### Q1: 为什么调整滑块后模型没有移动？

**A**: 检查以下几点：
1. 桌面伙伴窗口是否正在运行（设置中是否启用）
2. 是否已加载VRM模型
3. 打开浏览器开发者工具，检查是否有控制台错误
4. 查看是否有 "✓ 已设置模型位置偏移" 的日志

### Q2: 位置偏移的单位是什么？

**A**: 这是Three.js场景中的单位（通常等同于米）。具体显示效果取决于：
- VRM模型的原始尺寸
- 模型缩放设置
- 相机的位置和视野角度

### Q3: 能否添加更大的偏移范围？

**A**: 可以！修改 `src/views/Settings/PetSettings.vue`：

```vue
<input 
  type="range" 
  min="-5.0"  <!-- 从 -2.0 改为 -5.0 -->
  max="5.0"   <!-- 从 2.0 改为 5.0 -->
  step="0.1"
  v-model.number="petStore.settings.modelOffsetX"
  @input="handlePetSettingChange"
  class="slider"
/>
```

同时需要更新接口注释：

```typescript
// src/stores/petStore.ts
export interface PetSettings {
  modelOffsetX: number; // 模型左右偏移（-5.0 到 5.0）
  modelOffsetY: number; // 模型上下偏移（-5.0 到 5.0）
}
```

### Q4: 位置偏移和窗口位置有什么区别？

**A**:
- **窗口位置** (`positionX`, `positionY`)：桌面伙伴窗口在屏幕上的位置（像素坐标）
- **模型位置偏移** (`modelOffsetX`, `modelOffsetY`)：VRM模型在窗口内3D场景中的位置（3D坐标）

拖动桌面伙伴窗口改变的是窗口位置，而这个功能调整的是模型在窗口内的位置。
