## 快速测试步骤

### 测试 1：位置保存基本功能

```
✅ 操作步骤：
1. 启动应用（pnpm tauri dev）
2. 进入设置 → 小组件
3. 点击"添加时间组件"
4. 拖动小组件到屏幕左上角
5. 观察控制台，应该看到：
   📍 拖动后位置（逻辑坐标）: { x: ?, y: ? }
   💾 位置已保存（逻辑坐标）: ?, ?

8. 小组件应该出现在左上角（相同位置）✅

❌ 如果位置不对：
- 打开控制台查看加载日志

const stored = localStorage.getItem('aurora-widgets-settings');
console.log('保存的设置:', JSON.parse(stored));

// 查看特定组件

console.log('时间组件:', timeWidget);
```

### 清除所有小组件设置

```javascript
// 清除设置
localStorage.removeItem('aurora-widgets-settings');

// 刷新页面
location.reload();
```

### 手动验证位置

```javascript
// 检查保存的位置
const settings = JSON.parse(localStorage.getItem('aurora-widgets-settings'));
const widget = settings[0]; // 第一个组件
console.log('保存的位置:', { x: widget.x, y: widget.y });
console.log('保存的大小:', { width: widget.width, height: widget.height });
```

### 监控保存操作

```javascript
// 监控 localStorage 变化
const original = localStorage.setItem;
localStorage.setItem = function(key, value) {
  if (key === 'aurora-widgets-settings') {
    const data = JSON.parse(value);
    console.log('📦 小组件设置被更新:', {
      数量: data.length,
      时间: new Date().toLocaleTimeString()
    });
    data.forEach(w => {
      console.log(`  - ${w.type}: (${w.x}, ${w.y}) ${w.width}x${w.height}`);
    });
  }
  return original.apply(this, arguments);
};
console.log('✅ 监控已启动');
```

## 常见问题排查

### 问题 1：位置没有保存

**症状：** 拖动后重启，组件回到默认位置

**排查步骤：**

1. 查看控制台，拖动时是否看到 "位置已保存"？
   - 没看到 → 拖动监听可能没生效
   - 看到了 → 继续下一步

2. 检查 localStorage：
   ```javascript
   const settings = JSON.parse(localStorage.getItem('aurora-widgets-settings'));
   console.log('位置:', settings[0]?.x, settings[0]?.y);
   ```
   - 如果是默认值 (100, 100) → 保存失败
   - 如果是新位置 → 保存成功，加载可能有问题

3. 查看重启时的加载日志：
   - 应该看到 "从 localStorage 加载小组件设置"
   - 如果没有，检查 loadSettings() 是否被调用

### 问题 2：DPI 缩放下位置偏移

**症状：** 125% DPI 下，重启后位置偏移到右下角

**排查步骤：**

1. 查看拖动日志，是否有 "DPI 缩放因子"？
   ```
   🔍 DPI 缩放因子: 1.25
   ```
   - 没有 → scaleFactor() 调用失败
   - 有 → 继续下一步

2. 检查保存的是逻辑坐标还是物理坐标：
   ```javascript
   // 125% DPI 下，如果保存了物理坐标，值会是逻辑坐标的 1.25 倍
   const settings = JSON.parse(localStorage.getItem('aurora-widgets-settings'));
   console.log('保存的坐标:', settings[0]?.x, settings[0]?.y);
   // 如果值很大（如 1250），说明保存了物理坐标，应该转换为逻辑坐标
   ```

3. 确认创建窗口时使用的坐标：
   - 查看 "创建小组件窗口" 日志
   - 应该使用逻辑坐标

### 问题 3：窗口大小不保存

**症状：** 调整大小后重启，大小恢复默认

**排查步骤：**

1. 调整大小时，检查控制台：
   - 应该看到 "窗口大小变化" 和 "保存小组件大小"
   - 如果没有，ResizeObserver 可能没工作

2. 检查防抖是否生效：
   - 调整大小后等待 300ms
   - 应该在停止调整后才保存

3. 验证保存的数据：
   ```javascript
   const settings = JSON.parse(localStorage.getItem('aurora-widgets-settings'));
   console.log('保存的大小:', settings[0]?.width, settings[0]?.height);
   ```

### 问题 4：主窗口修改设置覆盖了位置

**症状：** 在设置中修改颜色后，位置变回默认值

**排查步骤：**

1. 修改颜色时，查看控制台：
   - 应该看到 "位置数据不一致，保留 localStorage 中的位置"
   - 如果没有，标志位机制可能失效

2. 检查标志位：
   ```javascript
   // 在 widgetStore.ts 中添加日志
   console.log('标志位:', {
     isSavingPosition: isSavingPositionMap.get(widgetId),
     isSavingSize: isSavingSizeMap.get(widgetId)
   });
   ```

3. 验证最终保存的数据：
   - 位置应该是拖动后的位置，不是默认位置
