**1.2 目录结构创建**
- `src/` - Vue 前端源代码
  - `components/` - Vue 组件
  - `composables/` - 组合式函数
  - `stores/` - Pinia 状态管理
  - `types/` - TypeScript 类型定义
  - `styles/` - 全局样式
  - `assets/` - 静态资源
  - `windows/` - 多窗口入口
- `src-tauri/` - Tauri 配置和 Rust 代码
  - `bin/` - Sidecar 可执行文件
  - `icons/` - 应用图标
- `aurora-core/` - C++ 后端源代码
- `scripts/` - 构建脚本

**1.3 基础页面实现**
- 主窗口（设置面板）
