# **Dock栏开发需求提示词**

## **一、 核心任务**

目前，应用中的Dock栏功能尚未实现，导致“设置”中相关的控制（如Dock开关、位置设置）无法生效。本次任务的核心目标是**从零开始实现一个功能完整的Dock栏**。

## **二、 核心功能与逻辑**

1. **图标管理**：  
   * **默认图标**：Dock栏创建时，应默认添加“此电脑”、“设置”、“控制面板”的图标。  
   * **图标操作**：用户必须能够自由添加新的应用程序图标，也能够移除Dock上的任何已有图标（包括上述的默认图标）。  
2. **位置与拖动**：  
   * **支持拖动**：Dock栏必须支持用户通过鼠标拖动来改变其在屏幕上的位置。  
   * **位置持久化**：拖动操作结束后，必须立即自动保存Dock栏的最后位置坐标。  
3. **位置加载逻辑（用户故事）**：  
   * **首次使用**：用户首次启动应用时，Dock栏在屏幕默认位置创建。  
   * **拖动后**：用户拖动Dock栏，松开鼠标后，新位置被保存。  
   * **重启应用**：用户关闭并重新打开应用时，Dock栏应在最后保存的位置被创建，而不是默认位置。  
   * **固定位置时**：见“新增设置”部分。

## **三、 新增设置与行为**

请在“设置”界面中为Dock栏新增以下三个布尔值（Boolean）开关，并实现其业务逻辑：

1. **始终置顶 (Always on Top)**：  
   * *逻辑*：开启时，Dock栏窗口应始终保持在所有其他应用窗口的最顶层。  
2. **固定位置 (Pin Position)**：  
   * *逻辑*：开启时，Dock栏的拖动功能被禁用，其位置被锁定在当前保存的坐标上。关闭时，恢复可拖动。  
3. **自动隐藏 (Auto-hide)**：  
   * *逻辑*：  
     * **隐藏**：当此开关打开时，如果用户的鼠标指针在一段时间内（例如2秒）未聚焦（Hover）在Dock栏的触发区域，Dock栏应自动平滑隐藏。  
     * **显示**：当鼠标指针重新移入Dock栏的触发区域时，Dock栏应立即平滑显示。  
     * **位置**：Dock栏需要保存其在隐藏前的位置，以便在正确的位置重新显示。

## **四、 个性化定制**

用户应能在“设置”中修改以下属性，所有修改必须**即时生效**，无需点击“应用”或重启程序。

* **Dock栏容器属性**：  
  * 长度 (Width/Height)  
  * 高度 (Height/Width)  
  * 透明度 (Opacity)  
  * 圆角值 (Border Radius)  
  * 背景色 (Background Color)  
* **图标属性**：  
  * 图标大小 (Icon Size)  
  * 聚焦动画 (Hover Animation)：例如放大、发光等效果。

**重要**：请确保这些设置是直接修改Dock栏窗口容器的属性，而不是在Dock窗口内再创建一个新容器来应用这些样式。必须确保这些功能真正生效。

## **五、 技术与性能要求**

1. **响应式系统**：  
   * 必须构建一个响应式的设置系统（例如使用观察者模式、信号或事件驱动），确保第四部分中的所有“个性化定制”设置都能即时反应到UI上。  
   * **严禁**使用定时器（如 setInterval）不断轮询（Polling）设置值，这种方式会占用过多内存和CPU。  
2. **DOM结构**：  
   * Dock栏的HTML/DOM结构应保持简洁、轻量化。  
   * 避免使用过多不必要的嵌套容器。一个“窗口背景容器”和一个“图标容器”应是主要结构。  
3. **样式隔离**：  
   * 为Dock栏创建全新的、独立的样式（CSS/Styles）。  
   * 必须确保Dock栏的样式不会与应用程序的其他界面样式发生冲突或串用。  
4. **性能**：  
   * 实现必须是轻量化的，注意避免内存泄漏，特别是在处理图标增删和事件监听时。
