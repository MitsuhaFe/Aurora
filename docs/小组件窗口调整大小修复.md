# 小组件窗口调整大小修复

## 更新日期
2025-11-03

## 问题描述

用户反馈：小组件无法通过拖动边缘调整窗口大小。

**原因：** 之前为了实现拖动功能，在整个窗口容器上绑定了 `mousedown` 事件，导致窗口边缘的 resize 事件被拦截。

## 问题分析

### 原始实现的问题

```vue
<template>
  <div 
    class="widget-container" 
    @mousedown="handleMouseDown"  <!-- 拦截所有鼠标事件 -->
  >
    ...
  </div>
</template>

<style scoped>
.widget-container {
  cursor: move;  <!-- 整个窗口都是 move 光标 -->
}
</style>
```

**问题流程：**

```
1. 用户将鼠标移到窗口边缘
   └─> 想要调整窗口大小

2. 鼠标按下事件被容器拦截
   └─> handleMouseDown 触发
         └─> 调用 startDragging()

3. 系统的 resize 处理器无法响应
   └─> 窗口无法调整大小 ❌
```

### Tauri 的窗口 Resize 机制

Tauri 的窗口边缘有一个**不可见的 resize 区域**（通常 5-10px 宽），当鼠标在这个区域时：
1. 系统会自动显示 resize 光标（如 `nwse-resize`、`ew-resize` 等）
2. 鼠标按下会触发系统的 resize 处理
3. 但如果我们的 `mousedown` 事件拦截了，resize 就无法工作

## 解决方案

### 1. 检测鼠标是否在窗口边缘

添加 `isNearWindowEdge` 函数：

```typescript
/**
 * 检测鼠标是否在窗口边缘（resize 区域）
 * @param e 鼠标事件
 * @param edgeSize 边缘区域大小（像素）
 * @returns 是否在边缘
 */
function isNearWindowEdge(e: MouseEvent, edgeSize: number = 8): boolean {
  const { clientX, clientY } = e;
  const { innerWidth, innerHeight } = window;
  
  // 检查是否在窗口边缘附近
  const nearLeft = clientX <= edgeSize;
  const nearRight = clientX >= innerWidth - edgeSize;
  const nearTop = clientY <= edgeSize;
  const nearBottom = clientY >= innerHeight - edgeSize;
  
  return nearLeft || nearRight || nearTop || nearBottom;
}
```

**参数说明：**
- `edgeSize = 8` - 边缘区域宽度，8px 是一个合适的值
  - 太小（< 5px）- 难以触发 resize
  - 太大（> 10px）- 拖动区域变小

### 2. 修改 handleMouseDown

在拖动前检查鼠标位置：

```typescript
async function handleMouseDown(e: MouseEvent) {
  if (!widget.value || !widgetId) return;
  
  // 如果位置已固定，禁止拖动
  if (widget.value.pinPosition) {
    return;
  }
  
  // 🔑 关键修复：如果鼠标在窗口边缘，不触发拖动，让系统处理 resize
  if (isNearWindowEdge(e)) {
    console.log('🖱️ 鼠标在窗口边缘，允许调整大小');
    return;  // 提前返回，不调用 startDragging()
  }
  
  // 其他区域才触发拖动
  if (!isInteractiveElement) {
    await appWindow.startDragging();
  }
}
```

### 3. 动态光标处理

添加 `updateCursor` 函数，根据鼠标位置显示正确的光标：

```typescript
/**
 * 动态更新光标样式
 * 在窗口边缘显示 resize 光标
 */
function updateCursor(e: MouseEvent) {
  if (widget.value?.pinPosition) {
    document.body.style.cursor = 'default';
    return;
  }
  
  const { clientX, clientY } = e;
  const { innerWidth, innerHeight } = window;
  const edgeSize = 8;
  
  const nearLeft = clientX <= edgeSize;
  const nearRight = clientX >= innerWidth - edgeSize;
  const nearTop = clientY <= edgeSize;
  const nearBottom = clientY >= innerHeight - edgeSize;
  
  // 设置相应的光标样式
  if (nearTop && nearLeft) {
    document.body.style.cursor = 'nwse-resize';  // 左上角
  } else if (nearTop && nearRight) {
    document.body.style.cursor = 'nesw-resize';  // 右上角
  } else if (nearBottom && nearLeft) {
    document.body.style.cursor = 'nesw-resize';  // 左下角
  } else if (nearBottom && nearRight) {
    document.body.style.cursor = 'nwse-resize';  // 右下角
  } else if (nearLeft || nearRight) {
    document.body.style.cursor = 'ew-resize';    // 左右边
  } else if (nearTop || nearBottom) {
    document.body.style.cursor = 'ns-resize';    // 上下边
  } else {
    document.body.style.cursor = 'move';         // 中间区域
  }
}
```

**光标类型说明：**
- `nwse-resize` - 西北-东南方向（↖↘）
- `nesw-resize` - 东北-西南方向（↗↙）
- `ew-resize` - 东西方向（↔）
- `ns-resize` - 南北方向（↕）
- `move` - 移动

### 4. 注册和清理事件监听器

```typescript
onMounted(async () => {
  // ... 其他代码
  
  // 添加鼠标移动监听器，动态更新光标
  document.addEventListener('mousemove', updateCursor);
});

onUnmounted(() => {
  // ... 其他代码
  
  // 移除鼠标移动监听器
  document.removeEventListener('mousemove', updateCursor);
});
```

### 5. 简化 CSS

移除会干扰 resize 的 CSS 样式：

```css
.widget-container {
  width: 100vw;
  height: 100vh;
  overflow: hidden;
  background: transparent;
  padding: 0;
  margin: 0;
  position: relative;
  /* 不设置默认光标，让 JS 动态控制 */
}

/* 重置子元素的光标，避免干扰 */
.widget-content > * {
  cursor: inherit;
}
```

## 修复后的工作流程

### 场景 1：拖动窗口（中间区域）

```
1. 鼠标移到窗口中间
   └─> updateCursor() 设置光标为 'move' ✅

2. 鼠标按下
   └─> handleMouseDown()
         ├─> isNearWindowEdge() = false
         └─> 调用 startDragging() ✅

3. 窗口跟随鼠标移动
   └─> 拖动成功 ✅
```

### 场景 2：调整窗口大小（边缘区域）

```
1. 鼠标移到窗口右下角
   └─> updateCursor() 设置光标为 'nwse-resize' ✅

2. 鼠标按下
   └─> handleMouseDown()
         ├─> isNearWindowEdge() = true
         └─> 提前返回，不调用 startDragging() ✅

3. 系统的 resize 处理器响应
   └─> 窗口大小调整成功 ✅
```

### 场景 3：固定位置（不可拖动）

```
1. 用户开启"固定位置"
   └─> widget.value.pinPosition = true

2. 鼠标移动
   └─> updateCursor() 设置光标为 'default' ✅

3. 鼠标按下
   └─> handleMouseDown() 提前返回 ✅

4. 窗口既不能拖动，也不能调整大小 ✅
```

## 技术要点

1. **边缘检测** - 使用 8px 作为边缘区域宽度
2. **提前返回** - 在边缘时不调用 `startDragging()`
3. **动态光标** - 根据鼠标位置实时更新光标样式
4. **事件清理** - 在 `onUnmounted` 中移除监听器
5. **固定位置保护** - 固定位置时禁用所有交互

## 边缘大小调整建议

如果觉得 8px 的边缘太小或太大，可以调整 `edgeSize` 参数：

```typescript
// 更小的边缘（更精确，但更难触发）
function isNearWindowEdge(e: MouseEvent, edgeSize: number = 5): boolean

// 更大的边缘（更容易触发，但拖动区域变小）
function isNearWindowEdge(e: MouseEvent, edgeSize: number = 10): boolean
```

## 已知限制

1. **角落优先级** - 如果同时在两个边缘（如右下角），优先处理角落 resize
2. **固定位置** - 固定位置时既不能拖动也不能 resize
3. **最小尺寸** - Tauri 窗口有最小尺寸限制（通常 200x200）

## 总结

通过检测鼠标是否在窗口边缘，我们成功地将拖动和 resize 功能分离：
- **边缘区域（8px）** → 系统 resize 处理
- **中间区域** → 自定义拖动处理

同时添加了动态光标反馈，让用户清楚地知道当前可以执行什么操作。

现在小组件既可以自由拖动，也可以调整大小了！🎉
