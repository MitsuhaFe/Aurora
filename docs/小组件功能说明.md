# Aurora 小组件功能说明

## 📊 功能概述

Aurora 小组件系统提供了一套可自定义的桌面监控组件，帮助用户实时监控系统状态和时间信息。

## 🎯 小组件类型

### 1. ⏰ 时间组件
显示当前时间、日期和星期几

**特性：**
- 实时更新（每秒）
- 大字体显示时间
- 清晰的日期和星期显示

### 2. 🌐 网络监控组件
实时监控网络流量和连接状态

**显示内容：**
- 上传速度（实时）
- 下载速度（实时）
- 总上传流量
- 总下载流量
- 本地 IP 地址

**更新频率：** 每秒

### 3. 💻 系统监控组件
监控计算机系统资源使用情况

**显示内容：**
- CPU 使用率（带进度条）
- 内存占用率（带进度条）
- 已用内存 / 总内存

**更新频率：** 每秒

### 4. 💾 磁盘监控组件
显示磁盘空间使用情况

**显示内容：**
- 所有磁盘列表
- 每个磁盘的使用百分比（带彩色进度条）
- 已用空间 / 总空间
- 挂载点信息

**进度条颜色：**
- 绿色：< 50% 使用率
- 橙色：50% - 80% 使用率
- 红色：> 80% 使用率

**更新频率：** 每5秒

## 🎨 个性化设置

每个小组件都支持以下个性化选项：

### 外观设置
- **背景颜色**：自定义小组件背景色
- **字体颜色**：自定义文本颜色
- **透明度**：10% - 100%，可调节小组件透明程度
- **圆角大小**：0 - 40px，调整小组件圆角

### 行为设置
- **始终置顶**：小组件是否始终显示在其他窗口之上
- **固定位置**：锁定小组件位置，禁止拖动

### 窗口特性
- **可调整大小**：通过拖动边框调整小组件大小
- **可拖动**：按住小组件背景可拖动（除非启用了"固定位置"）
- **无边框**：小组件窗口无标题栏和边框
- **透明窗口**：窗口背景完全透明，只显示组件内容

## 📝 使用说明

### 添加小组件

1. 打开 Aurora 设置页面
2. 点击左侧菜单的"小组件"
3. 在"添加小组件"区域，点击想要添加的组件类型按钮
4. 小组件窗口会立即显示在桌面上

### 管理小组件

在设置页面的"已添加的小组件"列表中：

- **开关切换**：启用或禁用小组件显示
- **设置按钮（⚙️）**：打开详细设置弹窗
- **删除按钮（🗑️）**：删除小组件（需要确认）

### 调整小组件

#### 移动位置
- 点击并按住小组件背景区域
- 拖动到目标位置
- 释放鼠标

#### 调整大小
- 将鼠标移至小组件边缘
- 当光标变为调整大小的箭头时
- 按住并拖动边框到想要的大小

### 个性化设置

1. 在小组件列表中点击"⚙️"按钮
2. 在弹出的设置弹窗中调整各项参数：
   - 使用颜色选择器选择背景色和字体色
   - 拖动滑块调整透明度和圆角
   - 勾选复选框启用置顶或固定位置
3. 设置会实时应用到小组件
4. 点击"完成"按钮关闭设置弹窗

## 💾 数据持久化

小组件的所有设置（包括位置、大小、个性化选项）都会自动保存到本地存储，应用重启后会自动恢复。

## 🔧 技术实现

### 前端技术栈
- **Vue 3**：组件框架
- **Pinia**：状态管理
- **TypeScript**：类型安全

### 后端技术栈
- **Rust**：系统信息获取
- **Tauri**：桌面应用框架
- **sysinfo**：系统监控库
- **local-ip-address**：网络信息获取

### 性能优化
- **按需更新**：不同组件使用不同的更新频率
- **轻量级窗口**：每个小组件使用独立的轻量级窗口
- **异步数据获取**：使用异步调用避免阻塞 UI
- **最小内存占用**：优化数据结构和更新逻辑

## 🐛 已知问题

1. **网络速度初始值**：首次启动时网络速度可能为 0，需等待第二次更新

## 💡 使用技巧

1. **性能考虑**：不建议同时开启过多小组件，以免影响系统性能
2. **布局建议**：使用"固定位置"功能可以防止误操作移动小组件
3. **配色方案**：建议使用深色背景配浅色文字，或浅色背景配深色文字，以获得最佳可读性
4. **透明度设置**：适当降低透明度可以让小组件更好地融入桌面背景
