## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    主窗口 (main)                         │
│  App.vue → 初始化 dockStore → 创建 Dock 窗口            │
│  Settings/Index.vue → Dock 设置界面 → v-model 绑定      │
└─────────────────────────────────────────────────────────┘
                           ↕ (响应式)
┌─────────────────────────────────────────────────────────┐
│               dockStore (Pinia + Vue watch)              │
│  • settings (响应式状态)                                 │
│  • icons (图标列表)                                      │
│  • watch → 监听变化 → 自动保存 + 应用到窗口             │
└─────────────────────────────────────────────────────────┘
                           ↕
┌─────────────────────────────────────────────────────────┐
│                   Dock 窗口 (独立)                       │
│  Dock.vue → 两层 DOM → dock.css（独立样式）             │
└─────────────────────────────────────────────────────────┘
```

## 🚀 如何使用

### 1. 启动应用

```bash
npm run tauri:dev
```

### 2. 查看 Dock

应用启动后，Dock 会自动显示在屏幕底部。

### 3. 修改设置

1. 打开主窗口
2. 进入"设置" → "Dock 栏"
3. 调整任意设置
4. 设置立即生效 ⚡

- **拖动**：按住 Dock 背景拖动
- **添加图标**：点击 ➕ 按钮

- **启动应用**：左键点击图标

## 🎨 设计亮点

### 1. 响应式架构
不使用轮询，完全事件驱动：
```typescript
watch(settings, async (newSettings) => {
  saveSettings();                    // 自动保存
  await applySettingsToWindow();     // 自动应用
}, { deep: true });
```

### 2. 即时生效
所有设置通过 `v-model` 双向绑定 + `watch` 监听实现零延迟生效。

### 3. 轻量化 DOM
```html
<div class="dock-container">        <!-- 背景容器 -->
  <div class="dock-icons">          <!-- 图标容器 -->
    <div class="dock-icon">...</div>
  </div>
</div>
```
仅 2 层嵌套，极简设计。

### 4. 样式隔离
`dock.css` 完全独立，使用 `scoped`，避免与主应用样式冲突。

### 5. 性能优化
```css
.dock-container {
  will-change: transform;
  transform: translateZ(0);  /* GPU 加速 */
}
```
