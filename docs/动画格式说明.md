# 动画格式说明与转换指南

## ⚠️ 重要提示

当前版本的桌面伙伴动画系统**仅支持 GLTF/GLB 格式的 VRM Animation 文件**。

## ✅ 支持的格式

- **GLTF** (.gltf) - 带 VRM Animation 数据的 GLTF 文本文件
- **GLB** (.glb) - GLTF 的二进制版本（推荐，文件更小）

## ❌ 不支持的格式

以下格式需要**先转换**为 GLTF/GLB：
- **VMD** (.vmd) - MikuMikuDance 动画格式
- **FBX** (.fbx) - Autodesk FBX 格式
- **BVH** (.bvh) - 动作捕捉数据格式

## 🔄 格式转换教程

### 方法一：使用 Blender（免费，推荐）

#### 安装所需插件
1. 下载 [Blender](https://www.blender.org/) (3.0 或更高版本)
2. 安装 [VRM Add-on for Blender](https://github.com/saturday06/VRM-Addon-for-Blender)
3. 安装 [Cats Blender Plugin](https://github.com/absolute-quantum/cats-blender-plugin)（可选，用于 MMD 转换）

#### 转换 FBX 到 GLTF
```
步骤：
1. 打开 Blender
2. File → Import → FBX (.fbx)
3. 选择你的 FBX 动画文件
4. 检查并调整动画（如需要）
5. File → Export → glTF 2.0 (.gltf/.glb)
6. 在导出设置中：
   - Format: 选择 "GLB" (二进制，推荐)
   - Animation: 勾选 "Animation"
   - 如果有 VRM 插件，确保启用 VRM 扩展
7. 点击 "Export glTF 2.0"
```

#### 转换 VMD 到 GLTF
```
使用 Cats Blender Plugin:
1. 安装 Cats 插件后，在侧边栏找到 "CATS" 标签
2. Import Model → Import MMD Model
3. 导入你的 VRM 或 PMX 模型
4. Import Motion → Import VMD
5. 选择 VMD 动画文件
6. 应用动画后，按照上述方法导出为 GLTF
```

### 方法二：使用 FBX2glTF（命令行工具）

适合批量转换 FBX 文件。

#### 安装
```bash
# Windows
下载预编译版本：https://github.com/facebookincubator/FBX2glTF/releases

# macOS (使用 Homebrew)
brew install fbx2gltf

# Linux
从源代码编译（参见 GitHub 仓库）
```

#### 使用
```bash
# 基本转换
FBX2glTF input.fbx

# 转换为 GLB（二进制）
FBX2glTF -b input.fbx

# 批量转换
for file in *.fbx; do FBX2glTF -b "$file"; done
```

## 🎯 VRM Animation 的要求

不是所有的 GLTF 文件都能用于桌面伙伴！文件必须满足以下要求：

### 必需条件
✅ 文件格式是 GLTF 或 GLB  
✅ 包含 VRM Animation 扩展数据  
✅ 动画骨骼与 VRM 标准兼容  

### 检查方法
1. 使用 Three.js 编辑器打开：https://threejs.org/editor/
2. 查看控制台，检查是否有 `VRMAnimation` 数据
3. 或使用 GLTF Validator：https://github.khronos.org/glTF-Validator/

## 🚨 常见错误与解决

### 错误 1: "不支持的动画格式: .fbx"
**原因**: 你尝试加载 FBX 文件  
**解决**: 使用 Blender 将 FBX 转换为 GLTF/GLB

### 错误 2: "文件中未找到VRM动画数据"
**原因**: GLTF 文件不包含 VRM Animation 扩展  
**解决**: 
- 确保使用支持 VRM 的工具导出
- 检查导出设置中是否启用了 VRM 扩展
- 使用专门为 VRM 设计的动画文件

### 错误 3: "此文件包含普通GLTF动画，但不是VRM Animation格式"
**原因**: 文件是普通的 GLTF 动画，不兼容 VRM  
**解决**: 
- 使用 Blender + VRM 插件重新导出
- 或寻找专门的 VRM Animation 文件

## 💡 最佳实践

1. **优先使用 GLB 格式**
   - 比 GLTF 文件更小
   - 加载速度更快
   - 单文件管理更方便

2. **测试动画兼容性**
   - 导入前先在 Three.js 编辑器中测试
   - 确认骨骼结构与你的 VRM 模型匹配

3. **优化文件大小**
   - 移除不必要的材质和纹理
   - 降低动画帧率（如 60fps → 30fps）
   - 使用 gltf-pipeline 压缩

4. **动画命名**
   - 使用有意义的文件名
   - 如：`wave_hand.glb`、`jump.glb`

## 🔧 高级技巧

### 使用 gltf-pipeline 优化文件
```bash
# 安装
npm install -g gltf-pipeline

# 转换 GLTF 为 GLB
gltf-pipeline -i input.gltf -o output.glb

# 压缩 (Draco)
gltf-pipeline -i input.glb -o output-compressed.glb -d
```

### 批量转换脚本（PowerShell）
```powershell
# 批量转换 FBX 到 GLB
Get-ChildItem *.fbx | ForEach-Object {
    $output = $_.BaseName + ".glb"
    FBX2glTF.exe -b $_.FullName -o $output
}
```

### 批量转换脚本（Bash）
```bash
#!/bin/bash
# 批量转换 FBX 到 GLB
for file in *.fbx; do
    FBX2glTF -b "$file"
    echo "转换完成: $file"
done
```
