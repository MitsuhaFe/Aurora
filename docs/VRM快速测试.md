# VRM 快速测试指南

## 🚀 快速排查问题

如果你的VRM文件加载失败，请按照以下步骤操作：

### 第一步：检查文件

✅ **确认文件是 .vrm 格式**
```
正确：model.vrm
错误：model.glb, model.fbx, model.obj
```

✅ **检查文件大小**
```
推荐：10MB - 50MB
可接受：< 200MB
过大：> 200MB（可能加载失败）
```

✅ **验证文件未损坏**
- 尝试用其他VRM查看器打开
- 重新下载文件

### 第二步：查看控制台日志

1. 打开Aurora桌面伙伴设置
2. 按 `F12` 打开开发者工具
3. 选择"Console"标签
4. 点击"选择模型"并加载VRM文件
5. 观察日志输出

**成功的日志应该包含：**
```
🐱 准备加载VRM模型...
📦 开始加载VRM模型...
✅ 模型下载完成
✅ VRM数据解析成功
🎉 VRM模型加载完成！
```

**如果看到错误，记录完整的错误信息**

### 第三步：尝试测试模型

下载一个小型测试模型验证功能：

**推荐测试模型（免费）：**
1. 访问 https://hub.vroid.com/
2. 搜索 "free" 或 "test"
3. 下载一个小文件（< 10MB）
4. 尝试在Aurora中加载

如果测试模型能加载，说明功能正常，问题在于原模型。

### 第四步：常见解决方案

#### 方案 A：简化文件路径
```
❌ 不推荐：
C:\Users\用户名\Documents\我的模型\角色 Ver2.0 (Final).vrm

✅ 推荐：
C:\Models\character.vrm
```

#### 方案 B：检查文件权限
```bash
1. 右键点击VRM文件
2. 选择"属性"
3. 检查"只读"是否勾选
4. 如果勾选，取消勾选
```

#### 方案 C：重启应用
```bash
1. 完全关闭Aurora
2. 重新启动
3. 再次尝试加载
```

## 📸 错误信息对照

### 错误类型 1
```
❌ 文件不包含有效的VRM数据
```
**原因：** 文件不是VRM格式或已损坏
**解决：** 确认文件是.vrm格式，尝试重新下载

### 错误类型 2
```
❌ 文件不存在或无法访问
```
**原因：** 路径问题或权限不足
**解决：** 移动文件到简单路径，检查权限

### 错误类型 3
```
❌ 3D场景未正确初始化
```
**原因：** WebGL不支持或显卡问题
**解决：** 更新显卡驱动，检查浏览器WebGL支持

### 错误类型 4
```
❌ 无法读取文件，请检查文件是否存在且未被占用
```
**原因：** 文件被其他程序占用
**解决：** 关闭其他可能使用该文件的程序

## 🎯 推荐的VRM文件

### 来源
- ✅ VRoid Hub (https://hub.vroid.com/)
- ✅ VRoid Studio 导出
- ✅ Booth.pm
- ⚠️ 其他来源（需验证格式）

### 规格建议
```
文件大小：    < 50MB
多边形数：    < 50,000
纹理分辨率：  2048x2048
骨骼数量：    < 100
VRM版本：     0.0 或 1.0
```

## 💡 专业提示

1. **第一次使用？**
   - 先用小型测试模型（< 10MB）
   - 确认功能正常后再加载正式模型

2. **模型显示异常？**
   - 调整光照设置（亮度 1.0-2.0）
   - 调整模型缩放（0.8x-1.2x）

3. **性能不佳？**
   - 选择低多边形模型
   - 关闭不需要的动画效果
   - 降低模型缩放
