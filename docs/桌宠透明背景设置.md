# 桌面伙伴透明背景设置指南

## 问题描述

桌面伙伴窗口显示时出现白色背景，而不是预期的透明效果。

## 根本原因

需要在**多个层级**同时设置透明背景才能实现完全透明效果：

1. **Tauri 窗口层**：窗口本身需要支持透明
2. **HTML/CSS 层**：HTML元素默认有背景色
3. **Vue 组件层**：组件容器可能有背景色
4. **WebGL 渲染层**：Three.js 场景和渲染器需要透明设置

## 完整解决方案

### 1. Tauri 窗口配置 (`src/stores/petStore.ts`)

创建窗口时设置 `transparent: true`：

```typescript
const window = new WebviewWindow('pet', {
  // ... 其他配置
  transparent: true,  // ✅ 启用窗口透明
  decorations: false, // ✅ 无边框
});
```

### 2. 全局 HTML/CSS 透明 (`src/views/Pet.vue`)

强制覆盖全局 CSS 中的白色背景：

```vue
<style>
/* 全局透明背景（针对桌面伙伴窗口） */
html, body, #app {
  background: transparent !important;
}

/* 确保 Three.js canvas 也是透明的 */
canvas {
  background: transparent !important;
}
</style>
```

**关键点**：
- 使用 `!important` 覆盖 `src/styles/main.css` 中的 `body { background: #ffffff; }`
- 同时设置 `html`, `body`, `#app` 三层
- 单独设置 `canvas` 元素

### 3. Vue 组件容器透明 (`src/App.vue`)

```vue
<style scoped>
.app-container {
  width: 100%;
  height: 100vh;
  overflow: hidden;
  background: transparent; /* ✅ 添加透明背景 */
}
</style>
```

### 4. Pet 窗口容器透明 (`src/views/Pet.vue`)

```vue
<style scoped>
.pet-window {
  width: 100vw;
  height: 100vh;
  overflow: hidden;
  position: relative;
  background: transparent; /* ✅ 透明背景 */
}
</style>
```

### 5. Three.js 场景透明 (`src/composables/useVrmLoader.ts`)

#### 场景背景设置

```typescript
// 创建场景
scene.value = new THREE.Scene();
scene.value.background = null; // ✅ 透明背景（不设置任何颜色）
```

#### 渲染器配置

```typescript
// 创建渲染器
renderer.value = new THREE.WebGLRenderer({
  alpha: true,              // ✅ 启用透明度通道
  antialias: true,          // 抗锯齿
  preserveDrawingBuffer: true,
});

// 设置完全透明的清除颜色
renderer.value.setClearColor(0x000000, 0); // ✅ 第二个参数 0 = 完全透明
```

**关键参数**：
- `alpha: true` - 启用 WebGL 的透明度支持
- `setClearColor(color, alpha)` - 第二个参数必须设置为 `0`

## 透明度层级结构

```
桌面
 └─ Tauri 窗口 (transparent: true)
     └─ HTML (background: transparent)
         └─ Body (background: transparent)
             └─ #app (background: transparent)
                 └─ .app-container (background: transparent)
                     └─ .pet-window (background: transparent)
                         └─ Canvas (background: transparent)
                             └─ WebGL Context (alpha: true, clearColor alpha: 0)
                                 └─ Three.js Scene (background: null)
                                     └─ VRM Model ✨
```

## 验证方法

1. **启动桌面伙伴**：在设置中启用桌面伙伴功能
2. **加载模型**：选择一个 VRM 文件
3. **检查背景**：
   - ✅ 应该看到桌面背景透过窗口
   - ✅ 只有 VRM 模型和提示文字可见
   - ❌ 不应该看到任何白色或黑色背景

## 常见问题

### Q1: 为什么需要 `!important`？

**A**: 因为全局 CSS (`src/styles/main.css`) 中有：

```css
body {
  background: #ffffff; /* 默认白色背景 */
}
```

这个样式会应用到所有窗口（包括桌面伙伴窗口）。使用 `!important` 可以在桌面伙伴窗口中强制覆盖这个设置。

### Q2: 为什么 `scene.background = null` 而不是 `transparent`？

**A**: Three.js 的 `scene.background` 接受以下值：
- `null` - 不渲染背景（完全透明）
- `THREE.Color` - 纯色背景
- `THREE.Texture` - 纹理背景

设置为 `null` 是实现透明背景的正确方式。

### Q3: `setClearColor(0x000000, 0)` 中的两个参数是什么？

**A**:
- 第一个参数 `0x000000` - 清除颜色（黑色，但因为透明度为0所以看不到）
- 第二个参数 `0` - 透明度（0 = 完全透明，1 = 完全不透明）

### Q4: 如果只设置其中一层会怎样？

**A**: 
- 只设置 Tauri 窗口透明 → HTML 层仍然是白色
- 只设置 HTML 透明 → Tauri 窗口不支持透明，仍然不透明
- 只设置 WebGL 透明 → HTML 层遮挡了 3D 内容

**必须所有层级都设置为透明才能达到最终效果。**

## 性能说明

启用透明窗口会带来一些额外的性能开销：

- **桌面合成**：需要与桌面进行透明混合
- **渲染开销**：每帧都需要处理透明度计算

不过对于桌面伙伴这种小窗口应用，性能影响可以忽略不计。
