# Aurora 桌面伙伴功能使用指南

## 功能概述

Aurora 桌面伙伴是一个基于 VRM 模型的 3D 桌面伙伴功能，支持自定义角色、动画、光照等多种效果。

## 主要特性

### 核心功能
- ✅ **VRM 模型支持** - 加载和显示 VRM 格式的 3D 角色
- ✅ **自由拖动** - 左键拖动桌面伙伴到任意位置
- ✅ **点击穿透** - 可以穿过桌面伙伴点击下方内容
- ✅ **始终置顶** - 桌面伙伴窗口保持在最上层
- ✅ **透明背景** - 无边框透明窗口，融入桌面

### 动画效果
- 🫁 **呼吸动画** - 自然的胸部起伏效果
- 👁️ **眨眼动画** - 自动眨眼让角色更生动
- 💫 **待机动画** - 待机时的自然动作

### 自定义选项
- 🔧 **模型缩放** - 调整角色显示大小 (0.5x - 2.0x)
- 💡 **光照设置** - 调整亮度和环境光/平行光颜色
- 🖥️ **窗口选项** - 置顶、点击穿透、任务栏显示等

## 使用指南

### 1. 准备 VRM 模型

VRM 模型可以从以下渠道获取：

- **[VRoid Hub](https://hub.vroid.com/)** - 官方模型分享平台
- **[Booth](https://booth.pm/)** - 日本创作平台
- **[VRoid Studio](https://vroid.com/studio)** - 自己创建角色

### 2. 启用桌面伙伴

1. 打开 Aurora 设置界面
2. 点击左侧菜单的"桌面伙伴"（🐱）
3. 点击"选择模型"按钮，选择 `.vrm` 文件
4. 开启"显示桌面伙伴"开关

### 3. 调整设置

#### 窗口属性
- **始终置顶** - 让桌面伙伴保持在所有窗口最上层
- **点击穿透** - 启用后可以点击桌面伙伴下方的内容
- **显示在任务栏** - 是否在任务栏显示桌面伙伴窗口图标

#### 模型属性
- **模型缩放** - 使用滑块调整角色大小
- 推荐值：1.0x (默认)

#### 光照设置
- **亮度** - 调整场景整体亮度 (0.1 - 2.0)
- **环境光颜色** - 设置环境光照颜色
- **平行光颜色** - 设置主光源颜色

#### 动画效果
- **待机动画** - 自然的待机动作
- **眨眼动画** - 自动眨眼效果
- **呼吸动画** - 胸部起伏效果

### 4. 交互操作

- **左键拖动** - 移动桌面伙伴位置
- **右键点击** - 打开快捷菜单
  - ⚙️ 设置 - 打开设置界面
  - ✅/⬜ 点击穿透 - 切换点击穿透状态
  - ❌ 关闭桌面伙伴 - 关闭桌面伙伴窗口

## 技术架构

### 前端技术栈
- **Three.js** - 3D 渲染引擎
- **@pixiv/three-vrm** - VRM 模型加载器
- **Vue 3** - 响应式 UI 框架
- **Pinia** - 状态管理

### 核心模块

#### 1. petStore.ts
状态管理模块，负责：
- 窗口创建和管理
- 设置的持久化存储
- 跨窗口通信

#### 2. useVrmLoader.ts
VRM 加载器组合式函数，负责：
- Three.js 场景初始化
- VRM 模型加载和渲染
- 动画更新循环
- 光照和缩放控制

#### 3. Pet.vue
桌面伙伴窗口组件，负责：
- 3D 场景容器
- 用户交互处理
- 上下文菜单

#### 4. PetSettings.vue
设置面板组件，负责：
- 模型选择
- 参数调整
- 实时预览

## 性能优化

### 资源占用
- **内存使用** - 取决于模型复杂度，通常 50-200MB
- **GPU 渲染** - 使用硬件加速
- **CPU 占用** - 低，主要用于动画更新

### 优化建议
1. 选择低多边形的 VRM 模型
2. 关闭不需要的动画效果
3. 降低模型缩放以减少渲染负担

## 常见问题

### Q: VRM 模型无法加载？
A: 检查以下几点：
- 确认文件是有效的 VRM 格式
- 检查文件路径中是否包含特殊字符
- 尝试使用不同的 VRM 模型
- 查看控制台错误信息

### Q: 桌面伙伴显示不完整或闪烁？
A: 可能的解决方案：
- 调整模型缩放
- 检查显卡驱动是否最新
- 尝试关闭其他占用 GPU 的程序

### Q: 无法拖动桌面伙伴？
A: 检查设置：
- 确认"点击穿透"已关闭
- 使用左键而非右键拖动
- 重启桌面伙伴窗口

### Q: 动画效果不生效？
A: 确认：
- 对应的动画开关已开启
- VRM 模型包含相应的 BlendShapes
- 查看控制台是否有错误
