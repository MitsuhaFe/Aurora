# 桌面伙伴设置即时生效功能

## 功能概述

桌面伙伴设置页面现在支持**即时生效**，用户在调整任何设置时，无需关闭或重启桌面伙伴，更改会立即应用到正在运行的桌面伙伴窗口上。

## 支持即时生效的设置

### 🪟 窗口属性
- **始终置顶** (`alwaysOnTop`)：立即生效
- **点击穿透** (`clickThrough`)：立即生效
- **显示在任务栏** (`showInTaskbar`)：立即生效

### 🎨 模型属性
- **模型缩放** (`scale`)：100ms 防抖后生效
- **水平位置偏移** (`modelOffsetX`)：100ms 防抖后生效
- **垂直位置偏移** (`modelOffsetY`)：100ms 防抖后生效

### 🔄 模型旋转
- **X轴旋转（俯仰）** (`rotationX`)：100ms 防抖后生效
- **Y轴旋转（偏航）** (`rotationY`)：100ms 防抖后生效
- **Z轴旋转（翻滚）** (`rotationZ`)：100ms 防抖后生效

### 💡 光照设置
- **亮度** (`brightness`)：100ms 防抖后生效
- **环境光颜色** (`ambientColor`)：100ms 防抖后生效
- **平行光颜色** (`directionalColor`)：100ms 防抖后生效

### 🎭 动画设置
- **待机动画** (`animations.idle`)：立即生效
- **眨眼动画** (`animations.blink`)：立即生效
- **呼吸动画** (`animations.breath`)：立即生效

## 技术实现

### 1. 跨窗口同步架构

Aurora 桌面伙伴系统使用**多窗口架构**：
- **主窗口**：显示设置界面（Settings）
- **桌面伙伴窗口**：独立的透明窗口（Pet.vue）

每个窗口都有自己独立的 `petStore` 实例，因此需要实现跨窗口同步机制。

### 2. 双重同步机制

#### 机制1：Tauri 事件系统（主要）

**发送端（petStore.ts）**：
```typescript
async function updateSettings(newSettings: Partial<PetSettings>) {
  Object.assign(settings.value, newSettings);
  saveSettings();

  // 尝试获取桌面伙伴窗口（支持跨窗口调用）
  const petWindowInstance = petWindow.value || WebviewWindow.getByLabel('pet');
  
  if (petWindowInstance) {
    // 发送设置变化通知
    await petWindowInstance.emit('pet-settings-changed', newSettings);
    
    // 更新窗口属性
    if (newSettings.alwaysOnTop !== undefined) {
      await petWindowInstance.setAlwaysOnTop(newSettings.alwaysOnTop);
    }
    
    if (newSettings.showInTaskbar !== undefined) {
      await petWindowInstance.setSkipTaskbar(!newSettings.showInTaskbar);
    }
  }
}
```

**接收端（Pet.vue）**：
```typescript
// 监听设置变化（通过 Tauri 事件）
await appWindow.listen('pet-settings-changed', (event) => {
  console.log('📢 收到设置变化通知:', event.payload);
  
  // 重新加载 localStorage 中的最新设置
  petStore.loadSettings();
  
  // 应用变化
  handleSettingsChanged(event.payload);
});
```

#### 机制2：localStorage 事件（备用）

**桌面伙伴窗口（Pet.vue）**：
```typescript
// 监听 localStorage 变化（跨窗口同步的备用机制）
window.addEventListener('storage', (event) => {
  if (event.key === 'aurora-pet-settings' && event.newValue) {
    console.log('🔄 检测到 localStorage 变化，重新加载设置');
    petStore.loadSettings();
    handleSettingsChanged(petStore.settings);
  }
});
```

**设置窗口（PetSettings.vue）**：
```typescript
onMounted(() => {
  // 监听 localStorage 变化（当桌面伙伴窗口修改设置时同步到主窗口）
  window.addEventListener('storage', (event) => {
    if (event.key === 'aurora-pet-settings' && event.newValue) {
      console.log('🔄 检测到其他窗口修改了设置，重新加载');
      petStore.loadSettings();
    }
  });
});
```

### 3. 设置应用处理

**Pet.vue - handleSettingsChanged**：
```typescript
function handleSettingsChanged(newSettings: any) {
  console.log('🔄 处理设置变化:', newSettings);
  
  if (!vrmLoader) return;

  // 更新缩放
  if (newSettings.scale !== undefined) {
    vrmLoader.setScale(newSettings.scale);
    console.log('✓ 已更新缩放:', newSettings.scale);
  }

  // 更新位置偏移（使用 ?? 运算符从 petStore 获取默认值）
  if (newSettings.modelOffsetX !== undefined || newSettings.modelOffsetY !== undefined) {
    const offsetX = newSettings.modelOffsetX ?? petStore.settings.modelOffsetX;
    const offsetY = newSettings.modelOffsetY ?? petStore.settings.modelOffsetY;
    vrmLoader.setPosition(offsetX, offsetY);
    console.log('✓ 已更新位置偏移:', { x: offsetX, y: offsetY });
  }

  // 更新旋转
  if (newSettings.rotationX !== undefined || newSettings.rotationY !== undefined || newSettings.rotationZ !== undefined) {
    const rotX = newSettings.rotationX ?? petStore.settings.rotationX;
    const rotY = newSettings.rotationY ?? petStore.settings.rotationY;
    const rotZ = newSettings.rotationZ ?? petStore.settings.rotationZ;
    vrmLoader.setRotation(rotX, rotY, rotZ);
    console.log('✓ 已更新旋转:', { x: rotX, y: rotY, z: rotZ });
  }

  // 更新光照
  if (newSettings.lighting) {
    const brightness = newSettings.lighting.brightness ?? petStore.settings.lighting.brightness;
    const ambient = newSettings.lighting.ambientColor ?? petStore.settings.lighting.ambientColor;
    const directional = newSettings.lighting.directionalColor ?? petStore.settings.lighting.directionalColor;
    vrmLoader.setLighting(brightness, ambient, directional);
    console.log('✓ 已更新光照:', { brightness, ambient, directional });
  }

  // 更新点击穿透
  if (newSettings.clickThrough !== undefined) {
    clickThrough.value = newSettings.clickThrough;
    appWindow.setIgnoreCursorEvents(newSettings.clickThrough);
    console.log('✓ 已更新点击穿透:', newSettings.clickThrough);
  }
  
  console.log('✅ 设置即时更新完成');
}
```

### 5. 防抖优化

**PetSettings.vue**：

为了避免频繁更新造成性能问题，实现了两种处理方式：

#### 方式1：防抖处理（用于滑块）
```typescript
// 100ms 防抖，避免滑块拖动时频繁触发
async function handlePetSettingChange() {
  if (debounceTimer !== null) {
    clearTimeout(debounceTimer);
  }
  
  debounceTimer = window.setTimeout(async () => {
    await petStore.updateSettings(petStore.settings);
  }, 100);
}
```

使用场景：
- 模型缩放滑块 (`@input="handlePetSettingChange"`)
- 位置偏移滑块 (`@input="handlePetSettingChange"`)
- 旋转角度滑块 (`@input="handlePetSettingChange"`)
- 亮度滑块 (`@input="handlePetSettingChange"`)

#### 方式2：立即执行（用于开关）
```typescript
// 立即执行，无延迟
async function handleToggleChange() {
  await petStore.updateSettings(petStore.settings);
}
```

使用场景：
- 所有开关按钮 (`@change="handleToggleChange"`)
- 颜色选择器 (`@input="handlePetSettingChange"`)

## 性能优化

### 1. 防抖机制
- **延迟时间**：100ms
- **适用对象**：滑块控件（scale, offset, rotation, brightness）
- **优势**：避免拖动滑块时每一帧都触发更新，减少CPU和内存使用

### 2. 部分更新
- 只发送真正改变的设置字段
- 接收端只处理有值的字段
- 避免不必要的计算和渲染

### 3. 智能回退
- 使用 `??` 运算符从 `petStore.settings` 获取默认值
- 确保即使部分字段缺失也能正常工作
