# 移除旧悬浮动画功能

## 📋 任务概述

移除了旧的 `hoverAnimation` 配置项，因为它与新的动画系统功能重复。

---

## 🔄 问题说明

### 旧系统（已移除）
在设置界面有一个"悬浮动画"下拉选择器，包含以下选项：
- **无动画**
- **缩放**
- **发光**
- **缩放 + 发光**

这个功能通过 JavaScript 动态设置 `inline style` 和 `data-animation` 属性来实现。

### 新系统（保留）
新的动画系统提供了更细粒度的控制：
- **悬浮放大** (`iconHoverScale`) - toggle 开关
- **悬浮发光** (`iconHoverGlow`) - toggle 开关
- 以及其他 6 种动画效果

新系统通过 CSS 类（如 `.has-hover-scale`、`.has-hover-glow`）和 CSS `:hover` 伪类实现，无需 JavaScript 干预。

### 重复的功能
旧的"悬浮动画"选项中：
- "缩放" = 新的"悬浮放大"
- "发光" = 新的"悬浮发光"
- "缩放 + 发光" = 同时启用"悬浮放大"和"悬浮发光"
- "无动画" = 同时禁用"悬浮放大"和"悬浮发光"

因此，旧功能完全可以被新系统替代。

### 3. `src/views/Dock.vue`

#### 移除事件监听器
```vue
<!-- 移除前 -->
<div
  class="dock-icon"
  @click.left="handleIconClick($event, icon)"
  @contextmenu.prevent.stop="handleContextMenu($event, icon)"
  @mouseenter="handleIconHover($event, true)"  <!-- ❌ 移除 -->
  @mouseleave="handleIconHover($event, false)"  <!-- ❌ 移除 -->
>

<!-- 移除后 -->
<div
  class="dock-icon"
  @click.left="handleIconClick($event, icon)"
  @contextmenu.prevent.stop="handleContextMenu($event, icon)"
>
```

**说明**：新的动画系统完全通过 CSS `:hover` 伪类触发，不需要 JavaScript 事件监听。

#### 移除处理函数
```typescript
// 移除前
/**
 * 处理图标悬浮
 */
function handleIconHover(event: MouseEvent, isEnter: boolean) {
  const target = event.currentTarget as HTMLElement;
  const iconContent = target.querySelector('.icon-content') as HTMLElement;
  
  if (!iconContent) return;
  
  const animation = dockStore.settings.hoverAnimation;  // ❌ 旧配置项
  
  if (isEnter) {
    // 应用悬浮动画
    if (animation === 'scale' || animation === 'both') {
      iconContent.style.transform = 'scale(1.2)';
    }
    if (animation === 'glow' || animation === 'both') {
      iconContent.style.filter = 'drop-shadow(0 0 8px rgba(102, 126, 234, 0.6))';
    }
  } else {
    // 移除悬浮动画
    iconContent.style.transform = 'scale(1)';
    iconContent.style.filter = 'none';
  }
}

// 移除后：此函数完全删除
```

**替代方案**：新系统通过 CSS 自动处理：
```css
/* 悬浮放大 */
.dock-icon.has-hover-scale:hover {
  transform: scale(1.15) !important;
}

/* 悬浮发光 */
.dock-icon.has-hover-glow:hover .icon-content {
  box-shadow: 0 0 20px rgba(102, 126, 234, 0.8), ...;
  filter: brightness(1.2);
}
```

## ✅ 优势对比

### 旧系统的问题
- ❌ 使用 JavaScript 动态设置 `inline style`，性能较差
- ❌ 无法利用 CSS 的 `:hover` 优化
- ❌ 选项有限（只有 4 种组合）
- ❌ 需要手动管理事件监听器
- ❌ 代码冗余，维护困难

### 新系统的优势
- ✅ 纯 CSS 实现，性能更好
- ✅ 利用浏览器原生 `:hover` 优化
- ✅ 更细粒度的控制（8 种独立动画）
- ✅ 可以自由组合（2^8 = 256 种可能）
- ✅ 无需 JavaScript 事件监听器
- ✅ 代码简洁，易于维护

---

## 🔄 迁移指南

对于已有的用户配置，行为变化如下：

| 旧配置 | 迁移后的等效配置 |
|-------|----------------|
| `hoverAnimation: 'none'` | `iconHoverScale: false` + `iconHoverGlow: false` |
| `hoverAnimation: 'scale'` | `iconHoverScale: true` + `iconHoverGlow: false` |
| `hoverAnimation: 'glow'` | `iconHoverScale: false` + `iconHoverGlow: true` |
| `hoverAnimation: 'both'` | `iconHoverScale: true` + `iconHoverGlow: true` |

**注意**：由于旧配置项已从接口中移除，首次加载时会使用新系统的默认值：
- `iconHoverScale: true` （默认启用）
- `iconHoverGlow: true` （默认启用）

这相当于旧系统的 `'both'` 选项。
